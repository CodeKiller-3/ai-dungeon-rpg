### 3.3 `js/systems/inventory.js`

`atkOf(id, level)` 的公式（唯一口径）：

```
atk = round( base + Σ_{k=2..level} rate(k) )      // rate(k) = 覆盖 k 的那一段
```

- 例：`atkOf('elite_fang_1', 4) = round(3 + 1.6×3) = 8`；`atkOf('elite_fang_5', 11) = round(12 + 1.2×8 + 3.0×2) = 28`。
- `recalcEquip`：`wAtk = atkOf(weapon, p.level)`；`p.def += w.bonus.def`；`maxHp` 仍走 `w.effect.maxHp`。
- `upgrade()`：
  - 候选排除 `elite:true`；只有精英刀且无可强化护甲 → `{ok:false, msg:'系统武器无法强化：它随你等级成长'}`，**不扣卷轴、不改 `upg`**。
  - 精英刀 + 有护甲 → 卷轴落到护甲。
- **S8 不需要改 `modal.js`**：`_confirm` 已把 `Inventory.use` 的返回值交给 `_report(res)` → `ui:notice`（D-14 既有，`modal.js:513-521`、`564`）。M1 只是让 `upgrade()` 带回可读 `msg`。
- 例外：若实测 `_report` 链路断路，允许最小回归修复并在报告单列；不得借机做第 4 页。

### 3.4 `js/systems/battle.js`（304 行）

### 4.3 突破时点（r2 的核心修正）

- 【实测·红队按 `d69-m1-6000.json` 反推】F4 出层 atk 中位 47，而 L9 封顶约 44 → **F4 出层已经是 L10**；`D-65` 的“F5 出层 10.33”是**出层**均值，不是入层。
- 因此把突破从 L10 移到 **L11**：L10 保持普通档 `+3/+3/+10`（面板不变），`+9/+4/+20` 落在 L11。
- F5 经验 `544.4 × 1.15 ≈ 626` → 正好越过 L10→L11 的 600，**L11 在 F5 清到接近尾声时触发**，即“站在巨龙面前”前一刻。
- 两种情形都成立：若实测 F4 出层其实是 L9，L10 落在 F5 前段（+3，小跳），L11 仍在 F5 尾段（+12/+7/+30，大跳）；设计不依赖某个具体入层等级。

**这一刻靠什么点燃**（不靠换刀）：
1. 等级 +12 atk 是主贡献，刀只贡献 +2（守夜 24→26）或 +3（烬牙 25→28）；
2. 同一批 F5 杂兵从 3 回合掉到 2 回合（见 §4.4）；
3. 龙的血条第一次“打得动”：L10 面板 50 对龙单次 38，L11 面板 65 单次 53（+39%），360 血从 10 击压到 8 击；
4. 系统语音播报“满级”（M2 文案 + M3 面板的“下一突破”行显示“已满级”）。

### 4.4 回合【复算】

| 对象 | 面板 50（L10 入 F5） | 面板 65（L11 烬牙） | 面板 63（L11 不换刀） |
|---|---|---|---|
| 大僵尸 88/10 | 3 | 2 | 2 |
| 死灵法师 100/6 | 3 | 2 | 2 |
| 面具兽人 98/8 | 3 | 2 | 2 |
| 天使 135/5 | 3 | 3 | 3 |
| 巨龙 360，含狂暴 | 10（打不动） | **8** | **8** |

- 巨龙算法（两段）：`dmg=max(1,round(atk²/(atk+def)))`，50% 血后 `def×1.3`。
  - atk 65：`4225/80=53`→4 击；`4225/84.5=50`→4 击，合计 **8**。
  - atk 63：`3969/78=51`→4 击；`3969/82.5=48`→4 击，合计 **8**。
  - atk 59：`3481/74=47`→4 击；`3481/78.5=44`→5 击，合计 **9**。
- **口径统一**：两段复算，面板 ≥60 → 8 击，59 → 9 击，50 → 10 击。r1 写“8 击”是漏了狂暴；红队的 9 对应 r1 面板 58–59；本版 L11 面板 63/65 → **8 击**。验收只认实测中位，带 8–9。

**五把刀的形状差异（不是平行线）**：断牙 L4→L11 只涨 4；裂颅在 L7–8 涨 5；霜噬每级 1.4 匀速；守夜 L8 起每级 2.2；烬牙 L10 起每级 3.0。同一把刀在不同等级是不同武器，“换刀”不再是唯一变强方式。
