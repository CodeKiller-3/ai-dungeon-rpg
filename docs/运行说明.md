# 运行说明（D-73）

> 目标：把仓库拷到任何一台 Windows 机器上，不装 Node、不装依赖，3 分钟内跑起来。
> 本文只写当前代码真实支持的步骤；验证页数量以 `preflight/selfcheck/page-baseline.json` 的 `count` 为准（当前 109）。

## 一、需要什么

| 项 | 要求 |
| --- | --- |
| 浏览器 | Microsoft Edge 或 Google Chrome（近两年版本即可）；**不要用 IE** |
| 运行时 | 无。零构建、零 npm、零后端 |
| 操作系统 | Windows / macOS / Linux 均可；下面的脚本命令按 Windows PowerShell 写 |
| 跑自动验证 | Windows PowerShell **5.1 及以上**（Win10/11 自带）或 PowerShell 7；需要装 Edge |
| 屏幕 | 建议 ≥ 1280×800；窄屏（320×568）也能玩，HUD 会切紧凑版 |

## 二、启动游戏（10 秒）

1. 打开仓库根目录。
2. **双击 `index.html`**，或右键 →「打开方式」→ Edge / Chrome。
3. 看到首屏菜单即成功：开始新游戏 / 继续游戏 / 玩法说明 / 设置 / 关于。
4. 第一次进游戏会有一层操作引导，按 Enter 关掉即可。

不需要起本地服务器：全部资源用相对路径，`file://` 直开可玩。

## 三、存档在哪、怎么清

| 键 | 内容 |
| --- | --- |
| `ai_dungeon_rpg_save_v1` | 游戏存档（楼层、坐标、角色、地图、图鉴、结局记录） |
| `aiDungeon_settings_v1` | 设置（打击感 / 静音 / 缩放 / 自适应难度 / 任务指引） |
| `aiDungeon_guided` | 是否看过首次引导 |

- 查看：浏览器 F12 → Application（应用）→ Local Storage → `file://`。
- **正常清档**：首屏「设置 → 清除存档」→ 按两次 Enter（第一次只提示，第二次才删）。
- 暂停中也能清档：Esc → 设置 → 清除存档。
- 隐私模式 / 换浏览器 / 换 `index.html` 所在路径，存档都不共通——`file://` 的 localStorage 按文件源隔离。

## 四、跑自动验证（可选）

在仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File preflight\selfcheck\run-all.ps1
```

预期结尾：

```
TOTAL=109 PASS=109 FAIL=0 NONE=0 MIXED=0
GUARD=OK expected=109 actual=109 missing=0 extra=0
```

- 只跑冒烟子集：加 `-SelfTest`（同时会刷新 `preflight/selfcheck/d22-selftest.json`，D-22 依赖它）。
- 脚本用 Edge headless 逐页加载 `preflight/verify_*.html`，读取页面标题里的 `PASS/FAIL {json}`；不需要联网。
- 机器上没有 Edge 时，脚本会报找不到浏览器；装 Edge 或改脚本里的 `$edge` 路径。
- 单页排查：直接用 Edge 打开对应 `preflight/verify_*.html`，看页面顶部文字与标题。
- 四策略回归（可选，约几分钟）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File preflight\selfcheck\d55-report.ps1 -Runs 50 -Out d55-after.json
```

## 六、最容易踩的坑

1. **双击后白屏 / 排版全乱**：默认浏览器不是 Edge/Chrome（常见是旧 IE 或某些国产壳）。右键 →「打开方式」重选；或在地址栏确认是 `file:///.../index.html`。
2. **按键没反应**：页面还没拿到焦点。先在画面上点一下再按方向键。
3. **没有声音**：浏览器禁止自动播放，第一次按键/点击后 BGM 才会响；也可按 K 检查静音开关。
4. **「继续游戏」是灰的**：本机没有存档，或刚清过档；开一局新游戏并返回主菜单后就会写入。
5. **跑验证全是 NONE**：`run-all.ps1` 没找到 Edge，或杀毒软件拦了 headless 启动；看脚本输出的错误行。
6. **换电脑后存档没了**：存档在浏览器本地，不随仓库走；要迁移就导出 Local Storage 的 `ai_dungeon_rpg_save_v1`。
