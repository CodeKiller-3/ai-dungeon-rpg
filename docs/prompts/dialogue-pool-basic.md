# DeepSeek/豆包 批量生成话术（L1 离线反应库·基础版）

> 对应 PLAN.md §20（三级 NPC 反应机制）。本文件是"给 DeepSeek（或豆包）的生成话术"，产出 `js/data/reactions.js` 的基础事件文本池。
> **当前只生成基础文本（不依赖剧情）**；剧情向对话按 §20.7 叙事内容后置策略，留待剧情定稿后的后期装配。

## 使用方式

1. 把下方「给 DeepSeek 的话术」整段复制，粘贴到 DeepSeek 或豆包对话。
2. 一次生成一个角色（复制一次、改角色名与事件视角），或一次全部角色。
3. 生成结果原样贴回豆包，由豆包整理去重、过滤出戏内容、写入 `js/data/reactions.js`。

## 角色设定（当前游戏 NPC）

| 角色 | 位置 | 人设语气 |
|---|---|---|
| 守门人 | 地牢入口 | 沉稳、警告语气，话少但有力 |
| 商人 | 商店 | 精明、推销语气，带点市侩 |
| 向导 | 随机遭遇 | 神秘、提示语气，话里有话 |

## 给 DeepSeek 的话术（守门人版，模板）

```
你是游戏文本编剧。现在为像素地牢 RPG《AI勇者闯地牢》批量生成 NPC 反应台词。
要求：
1. 每条 1-2 句，中文，符合角色人设与语气（沉稳、警告语气，话少但有力）。
2. 不包含任何具体剧情、任务、人名或世界观专有设定（现在剧情未定稿，全部用通用表达，不提及任何具体 Boss、地名、传说）。
3. 同一事件下 8 条必须互不相同，避免"啊""哦"等无效开头和重复用词。
4. 语气贴近像素地牢游戏氛围，带一点黑色幽默，不使用现代网络用语。
5. 输出格式：纯 JSON 对象，不要多余文字。键为事件 tag，值为字符串数组。

角色：守门人
事件与条数：
- greeting 打招呼 8 条（回应玩家问候，简短）
- idle 闲聊 8 条（关于地牢的泛泛之言，不涉及具体设定）
- kill 击杀怪物 8 条（简短评语）
- kill_boss 击杀头目 8 条（通用"强敌"表达，不提具体名字）
- hurt 受击 8 条（忍痛/鼓励）
- low_hp 残血 8 条（紧急提示）
- gold 获得金币 6 条
- pickup_item 拾取道具 6 条
- death 死亡 10 条（通用悼词，不说教）
- victory 通关 8 条（通用胜利致辞）
共 84 条。开始生成。
```

## 验收判据（对应 §20.5）

- 每角色每事件 6-10 条；同 tag 内容互不相同；
- 无具体剧情/人名/Boss/地名（现为通用版）；
- 中文、1-2 句、无网络用语；
- 死亡/通关文本语气与角色一致。
