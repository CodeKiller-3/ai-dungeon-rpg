## 总判

| 组 | 判决 | 一句话 |
|---|---|---|
| 1. 三只 Boss 的专属剪影 | **达标** | 三只都不是放大版杂兵；龙能认出，但它的"Boss 感"最弱 |
| 2. 特效遮盖与飘字 | **部分达标** | 敌人受击的遮挡已消失；玩家的受击帧没有给出实拍，"玩家主体始终可读"未被证明 |
| 3. 墙地明度与战斗背景 | **部分达标** | 五层能分辨出是五个楼层，但仍是同一座舞台换五张壁纸；F2/F3 背景会和同色敌人打架 |

## 1. 三只 Boss 是否算「专属剪影」

### 看到什么

**地牢巨龙**（[dragon-1x.png](../../preflight/artifacts/d86/dragon-1x.png) / [dragon-8x.png](../../preflight/artifacts/d86/dragon-8x.png) / [dragon-states-4x.png](../../preflight/artifacts/d86/dragon-states-4x.png) / [boss-f5.png](../../preflight/artifacts/d86/boss-f5.png)）

- 108px 实战尺寸下，角、吻部、黄眼、单侧展开的翼、橙色腹甲、白爪、尾刺都在，能认出是"龙形生物"。
- 但它是三只里最不像"终局"的：身体是一整块暗酒红，翼是一块平三角，腹甲是四条等宽橙条；在 F5 的紫色地砖上，暗红对暗紫，剪影靠黑描边撑住，第一眼读成"一只很大的飞行怪"，不是"地牢之主"。
- 它的 Boss 感目前由**尺寸（108px）+ 350 血条 + 【BOSS】字样**提供，不是由剪影本身提供。这是和另外两只最大的差别。

**独眼酋长**（[ogre_boss-1x.png](../../preflight/artifacts/d86/ogre_boss-1x.png) / [ogre_boss-8x.png](../../preflight/artifacts/d86/ogre_boss-8x.png) / [ogre_boss-states-4x.png](../../preflight/artifacts/d86/ogre_boss-states-4x.png) / [boss-f2.png](../../preflight/artifacts/d86/boss-f2.png)）

- 单眼、双獠牙、肩上的斧、腰带金扣、外张的双臂：不看名字也知道"这只比杂兵大一级"。
- 1x 下最大的识别点是白眼球+黑瞳和右侧的斧，两者都成立。
- 攻击帧低头、张嘴，剪影有变化；受击帧几乎同 idle，但这是动画问题，不是剪影问题。

**僵尸王**（[zombie_king-1x.png](../../preflight/artifacts/d86/zombie_king-1x.png) / [zombie_king-8x.png](../../preflight/artifacts/d86/zombie_king-8x.png) / [zombie_king-states-4x.png](../../preflight/artifacts/d86/zombie_king-states-4x.png) / [boss-f4.png](../../preflight/artifacts/d86/boss-f4.png)）

- 金冠、紫披风、权杖、肋骨甲、绿皮：三只里身份最清楚的一只，1x 下也能一眼读成"王"。
- 三态（idle / attack / hurt）在 4x 下几乎同帧，动作可读性最弱；但"专属剪影"这一项它是过关的。

### 是不是放大版杂兵

不是。三组对照的轮廓 IoU 分别是 **0.4881 / 0.6907 / 0.6700**（[compare-dragon-vs-大僵尸.png](../../preflight/artifacts/d86/compare-dragon-vs-大僵尸.png)、[compare-ogre_boss-vs-骷髅士兵.png](../../preflight/artifacts/d86/compare-ogre_boss-vs-骷髅士兵.png)、[compare-zombie_king-vs-大僵尸.png](../../preflight/artifacts/d86/compare-zombie_king-vs-大僵尸.png)），三只都换掉了旧帧组，不再是 `ogre → ogre_boss`、`big_zombie → zombie_king`、`big_demon → dragon` 的复用关系。

但对照选得偏轻松：独眼酋长对的是**骷髅士兵**，不是它当年复用的那只食人魔；龙对的是大僵尸，不是被替换的大恶魔。即便如此，按旧图对比，结论仍成立——三只是新剪影，不是放大。

### 判决与最疼的一处

**达标。** 但最疼的是**龙**：它有龙形，没有"王气"。角、翼、腹甲三件事都成立，却没有一个能在 0.2 秒内说明"我是最终 Boss"的高对比符号（金冠、斧、发光眼、口中火，任选一个）。现在它和 F5 杂兵的区别主要靠体型和血条。

## 2. 特效遮盖与飘字

### 看到什么

[命中帧-前后对照.png](fix/命中帧-前后对照.png)：

- 左（修复前）：90×90 白闪矩形把史莱姆整只涂成白方块，眼睛、嘴、轮廓全消失；伤害数字 -9 压在脸上；右侧还有一块 `#222` 黑箱。
- 右（修复后）：史莱姆恢复成完整剪影，眼睛、嘴、腹部的层次都在；数字 -9 移到头顶上方 22px，落在空背景上；黑箱消失。
- [hit-f1.png](fix/hit-f1.png) 的整帧实拍确认了同样的结果：数字在敌人上方，主体没有被二次遮挡，也没有出现新的边框、色块或抖动噪点。

### 有没有新的遮挡或噪音

没有新增遮挡。数字虽然变成了画面里最亮的橙色元素之一，但它落在空背景上，带黑描边，读起来是"反馈"而不是"污渍"。

唯一算噪音的是文字层：金色的【高伤】标题和下面两行战报在说同一件事（"你对史莱姆造成 9 伤害"），一屏里重复三遍。这是旧问题，不是这次修复引入的，但它会稀释数字的力度。

### 判决与最疼的一处

**部分达标。** 敌人受击这一侧可以判过：遮挡消失、数字离开轮廓、没有新噪音。

但任务问的是"**玩家主体**是否始终可读"，而给出的对照只拍了**史莱姆被玩家打**的帧；旧报告里真正刺眼的是玩家被反击时的 90×90 红矩形。玩家受击帧没有实拍，所以"始终可读"这句话目前没有被证明。实现上大概率是同一个裁剪函数，但复判只能按图说话。

即使玩家侧也修好了，最疼的仍在：**数字只是"不再挡脸"，还没有"打得疼"。** 命中帧里没有落点火花、没有方向性斩击、没有受击形变，重量仍然由战报文字承担，不由画面承担。

## 3. 墙地明度与战斗背景

### 墙地：数值上真的修好了

[墙地明度-改前改后-F1.png](fix/墙地明度-改前改后-F1.png) 的口径写得很清楚：

- 地板 **60.0** 不变；
- 墙身 **50.5 → 27.4**，墙顶 **65.5 → 38.9**；
- 地−墙身 **9.5 → 32.6**，地−墙顶 **−5.5 → +21.1**。

改法是"原素材叠纯黑（墙身 0.45 / 墙顶 0.40）"，也就是**渲染期压暗**，不是重画材质。效果是实打实的：F1 原来"墙顶比地板亮 5.5"的反转被扳回来了，地板第一次成为画面里最亮的水平面。

去色行里，地板是较亮的中灰网格，墙身是更暗的砖面，**"哪边能走"在材质样本层面已经能读出来**。[explore-f3.png](fix/explore-f3.png) 也成立：橙红地板是亮的路，暗红墙是边界，火把光池仍然把玩家托出来。

但要如实说两点：
1. 这是**压暗**，不是**换材质**。地砖仍然是带砖缝、带上高光下阴影的"砌块"，只是现在比墙亮；"地板像砖"这件事没变。
2. 在实景里，火把附近仍会出现局部反转。[explore-f1-gray.png](fix/explore-f1-gray.png) 的上缘那几条最亮的横线，仍然是墙顶的压顶高光，不是路。全局压暗遇上游局部加光，压顶又被打回最亮。

### 战斗背景：五层能分辨，但不是五个地方

[battle-f1.png](fix/battle-f1.png) 到 [battle-f5.png](fix/battle-f5.png) 是同一套构图：

- 顶部一条地砖带（0–184px）；
- 中间一条纯色暗带（184–430px），所有文字都在这里；
- 底部一条地砖带（430–640px）；
- 没有门、没有火把、没有 boss 前厅、没有地面阴影，只有地砖的花色在换。

所以第一问"五层能不能分辨"——**能**。F1 暗灰、F2 土黄、F3 熔岩红、F4 冰蓝、F5 暗紫，五张图并排不会认错层。

第二问"去色后是否看得出哪里能走"——**在材质样本和探索帧里能**（32.6 / 21.1 的差值），但战斗背景只有地砖带，没有"墙/地"对照，这一问在战斗图里不成立。

第三问"背景有没有抢主体"——**有一部分在抢**：

- [battle-f2.png](fix/battle-f2.png)：兽人战士的棕色护甲和土黄地砖同族，靠绿皮和黑描边撑住；
- [battle-f3.png](fix/battle-f3.png)：沃古尔是红的，地砖也是红的，整只怪几乎融进背景，只剩轮廓；
- [boss-f5.png](../../preflight/artifacts/d86/boss-f5.png)：暗红龙对暗紫砖，是同类问题；
- F1 的史莱姆、F4 的米色僵尸、F5 的白色天使反而对比最好——因为敌人和背景不同色，不是因为舞台做了保护。

**背景最亮的地方，恰好是敌人站的那条砖带。** 没有暗角、没有主体后方压暗、没有接触阴影，主体只能靠描边和色相差异活下来。

### 判决与最疼的一处

**部分达标。** 墙地明度这一刀是有效的；战斗背景解决了"五层看起来一样"的问题，但没有解决"这是一个地方"的问题。

最疼的一处：**战斗舞台是"换壁纸"，不是"搭舞台"。** 五张图的构图、留白、砖带高度、文字位置 100% 相同，只有地砖花色不同。作者性提升很小——它让玩家知道"我在第几层"，但没有让玩家感到"我站在哪里"。

## 4. 作者性：哪一组真的往前走了

- **Boss：真的往前走了。** 三只都是新剪影，旧的"Boss = 放大杂兵"关系被切断了。僵尸王和独眼酋长有角色感；龙是唯一一只"新，但还没有性格"的。
- **特效：修的是缺陷，不是作者性。** 画面变干净了，但命中反馈仍然是一个通用数字，没有属于这套游戏的打击语言。
- **墙地/战斗背景：一半是数值修正，一半是换壁纸。** 压暗墙身是有效的技术修正；战斗背景的五层花色是有效的识别；但"同一座两段式舞台"没有变，作者性只加了一个色相。

## 5. 如果只再动一处

- Boss 组：给龙一个**高对比的身份符号**（发光眼/口火/亮色翼膜三选一），让它不靠血条也能被认成终局。
- 特效组：补一张**玩家受击帧**的实拍，把"始终"证明掉；再谈重量。
- 战斗背景组：在演员身后加**局部压暗/接触阴影**，先把 F2 兽人、F3 沃古尔、F5 龙从同色背景里救出来；这比再换一层壁纸有效。
