## 1. 五层战斗背景：五个地方成立了吗

### 看到什么

[bg-five-together.png](../../preflight/artifacts/d88/bg-five-together.png) 并排看，五层的空间语义都能读出来：

- **F1 石厅**（[bg-f1.png](../../preflight/artifacts/d88/bg-f1.png)）：石墙 + 中央拱门 + 两侧火把架，史莱姆站在拱门前。这是"厅"。
- **F2 营地**（[bg-f2.png](../../preflight/artifacts/d88/bg-f2.png)）：整排木栅栏 + 右侧板条箱 + 左侧火把，兽人站在栅栏前。这是"营地"的轮廓。
- **F3 熔岩裂谷**（[bg-f3.png](../../preflight/artifacts/d88/bg-f3.png)）：左右两池熔岩 + 中央黑平台，沃古尔站在平台上。这是"裂谷"。
- **F4 墓室**（[bg-f4.png](../../preflight/artifacts/d88/bg-f4.png)）：壁龛、立柱、石棺台、两侧蓝色壁灯，大僵尸站在石棺台上。这是五层里最像"房间"的一张。
- **F5 王座前厅**（[bg-f5.png](../../preflight/artifacts/d88/bg-f5.png)）：中央台阶高台 + 两侧王旗立柱 + 两个火把，巨龙站在台上。这是"前厅"。

**"还是同一套骨架换装饰"吗？** 分两层答：

- **布景层：不是。** 五层各有独立的建筑/道具组合（拱门、栅栏、熔岩、壁龛、王座），不是把同一张图染五种色。这是第三拨最大的进步。
- **调度层：还是。** 敌人固定在画面上方、玩家固定在下方、中间 246px 永远是文字区；每张图都是"上景 + 中空 + 下地"的三段式。五层换了布景，没有换舞台调度。

所以它们是**五个舞台布景**，不是五个可进入的空间。对回合制 2D 战斗来说这可以接受，但"空间感"仍有一层窗户纸。

### 哪一层只是符号堆叠

- **F2 最明显。** 木栅栏 + 板条箱 + 火把，三个"营地名词"并置，但没有帐篷、没有营火、没有门；火把是一根悬在黑色中景里的落地灯（灯杆底端离下方地面带还差约 30px），没有站在地上。它读成"夜晚的栅栏"，不是"兽人营地"。
- **F3 次之。** 两池熔岩被画幅左右边缘切断，像两条橙色包边；中央平台和熔岩之间没有桥、没有落差、没有前景岩石，"裂谷"的深度是靠颜色暗示的。更麻烦的是熔岩比沃古尔更亮，红怪站在红浆前，主体被背景压了一头。
- **F5 是"明信片"，但成立。** 王座、台阶、王旗、火盆都在讲同一件事（Boss 间），对称得有点刻意，但至少是一个完整构图。
- **F1 / F4 是真正的房间。** F4 的壁龛有进深、壁灯贴在侧墙上、石棺台承托僵尸，三者咬得住。

### 判决与"只改一处"

**达标。** 从"五张壁纸"跨到"五个布景"，这是作者性真正往前走的一轮。

只改一处：**把所有悬空的火把架落回地面或墙面，并给演员脚下加一条接触阴影。** F1/F2/F5 的灯杆都浮在中景黑带里，这是"布景板"感的最大来源；一盏灯站在地上，房间才开始有地板。

## 2. 龙加发光眼：0.2 秒够不够

### 看到什么

- [dragon-eyes-before-after-8x.png](../../preflight/artifacts/d88/dragon-eyes-before-after-8x.png)：改前是两条暗黄短横，龙头和暗红身体糊在一起；改后是两颗亮橙方眼，外圈有一层柔和的暗红光晕，光晕没有硬边，衰减自然。
- [dragon-eyes-8x.png](../../preflight/artifacts/d88/dragon-eyes-8x.png)：眼睛位置在头骨前部、双目的透视关系正确；颜色是暖橙，和暗红身体同族，靠明度而不是靠撞色跳出来。
- [dragon-1x.png](../../preflight/artifacts/d88/dragon-1x.png) 与 [bg-f5.png](../../preflight/artifacts/d88/bg-f5.png)：1× 实显下，眼睛是龙身上最亮的两点，光晕约 20px，能在一眼内看到"它在看我"。

### 够不够"终局"

眼睛解决的是**"活的"**，不是**"终局"**。

- 它让龙从"一块暗红剪影"变成了"有视线的主体"，这是真提升；
- 但 1× 下，龙仍然是 108px，和独眼酋长、僵尸王同高；王座高台比它更抢眼，350 血条和【BOSS】字样仍在替它承担身份；
- 缺的不是光晕衰减（现在这层已经对了），也不是颜色（橙对紫是对的），而是**体量**：终局 Boss 应该在画面上占据比前两只更大的面积，或者有一个"超出画框"的姿态（双翼展开、抬头、身体前压）。

### 判决与"只改一处"

**部分达标。** 眼睛是有效的细节，不是结构解。

只改一处：**把龙放大到约 1.35×，压低站姿、让翼展更宽，占住王座台面。** 眼睛不用再亮，体量会替它说话。

## 3. 打击表达：重量做出来了吗

### 7 帧里实际发生了什么

[hit-sequence-7frames.png](../../preflight/artifacts/d88/hit-sequence-7frames.png) 的 7 帧（t=0/30/60/90/120/150/180）：

- **t=0**：兽人整只被白色剪影闪白（不是矩形，眼睛、獠牙、轮廓都还在），-10 已经在头顶，战报已经结算。
- **t=60**：闪白退去，兽人恢复绿色，身上出现一圈淡绿冲击环。
- **t=120**：冲击环仍在，兽人右侧爆出一小簇橙色火花。
- **t=180**：环与火花消失，兽人回到 idle，-10 还挂着。

**节奏**：全部发生在 180ms 内，没有慢动作，没有拖长镜头，仍然是一次快速交锋。这一点是达标的。

**三样里哪样真起作用**：

- **斩击方向：真起作用。** 方向由白/绿弧线和玩家反击帧里那条横跨画面的白色斩击弧承担。它让"谁打谁"读得出来。
- **落点火花：一半是装饰。** 橙色火花只有一小簇，出现在兽人右侧，不在玩家剑与敌人的接触点上；它证明"打中了"，但不证明"从哪来"。
- **受击顿挫：静帧里读不出来。** 7 帧的栅栏、火把位置完全对齐，没有可见的定格帧或屏震；如果实现里有 40–80ms hitstop，这几张图没有把它拍出来，不能算"做出来了"。

**玩家被反击帧**（[hit-player-counter.png](../../preflight/artifacts/d88/hit-player-counter.png)）：玩家是红色剪影闪白，骑士的头盔、肩线、剑仍在；白色斩击弧从敌人方向斜切下来，-10 落在血条右侧，没有压住玩家身体。**这一帧能读成"我被打中了"**，旧的 90×90 红矩形确实没了。

代价：那条白色斩击弧会横穿玩家血条，短暂盖住 70/140 的血量数字。只有一帧，字还认得出，但这是新引入的小遮挡，下一版应该让弧线绕开血量数字。

### 判决与"只改一处"

**部分达标。** 遮挡问题解决了，方向感有了，节奏仍然快；但重量还是"特效打在静止靶子上"。

只改一处：**让身体动起来，而不是再加粒子。** 玩家攻击时向上顶 6–8px 再回位，敌人受击时向后退 3–4px 并轻微倾斜，接触点加 50ms 定格。一次位移比十簇火花更能说明"力传过去了"。

## 4. 酋长对照基线修正：结论要不要改

### 看到什么

- [boss-vs-ogre-1x.png](../../preflight/artifacts/d88/boss-vs-ogre-1x.png)：左边骷髅、中间普通食人魔、右边独眼酋长。普通食人魔是窄长的棕色方块，两只白眼、无武器；酋长宽了近一倍，单眼、双獠牙、头盔尖刺、右手斧、金腰扣。
- [boss-vs-ogre-8x.png](../../preflight/artifacts/d88/boss-vs-ogre-8x.png)：8× 下更清楚——酋长的眼睛是一个带橙色眶的白色大方块，普通食人魔只有两条白色横缝；酋长的斧和腰带是新增结构，不是放大后的色块。

### 结论

**之前的结论站得住，而且更硬了。** 独眼酋长不是"放大版食人魔"：它的比例、面部结构、武器、腰带、腿脚数量都变了。上一轮"对骷髅"的对照确实偏轻松，但即使换成真正的复用源，结论仍是"独立剪影"。

旧 caveat 撤销：这一只不需要再修。

### "只改一处"

这一组没有需要改的美术问题。若只做一件事，**把龙的旧基线（vs 大恶魔）也补一张同规格对照**，纯为证据闭环，不涉及画面。

## 5. 作者性：哪一组真的往前走了

- **五层背景：真的往前走了。** 从"同骨架换壁纸"到"五个可命名的布景"，这是三轮里作者性提升最大的一次。但它仍是布景，不是空间；F2/F3 是名词堆叠，F1/F4 是房间。
- **龙眼：是细节，不是作者性。** 眼睛让龙"活了"，但终局的重量仍由王座、体型、血条和字样承担；它看起来努力了，也确实好看，但没有改变"这只龙是谁"。
- **打击：方向弧是真正的作者性决策；火花是装饰；身体没动。** 这一轮把"遮挡"修好了，把"方向"做出来了，但"重量"还没有落到身体上。
- **酋长基线：是验证，不是创作。** 结论更可信，但没有新增作者性。

## 6. 如果四组只允许再改一处

**改打击的身体位移。** 背景已经从"壁纸"变成"布景"，龙眼已经能把脸点亮；现在每次战斗最缺的是"人被打动了"这一下。玩家顶出去、敌人退半步、接触点停 50ms——这比再画第五张背景、再调亮龙眼，都更能改变这个游戏的手感。
