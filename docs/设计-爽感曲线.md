## 0. 结论摘要

1. **现有曲线只能在前两层做出「变强→碾压」**：F1→F2 的面板 atk 14→21（+50%）；F2 独眼酋长改到 120/12/8 后 M1 到 F3 从 4/50 抬到 29/50（D-42），D-43 的补给改动后进一步到 **43/50**（只有 7 局死在 F2）；但 F3 没有装备跳变，D-34 的「期望攻击」基线只从 20.125 涨到 23.75（+18%），F4 又有 27/50 的 M1 死亡，F5 的 M1 通关是 0/50（来源：D-41、D-42、D-43、D-50）。
2. **卡点在 F3 和 F4，不在 F5 的 Boss 数值本身**：F3 需要一次「买不到的爆装」把面板 atk 从 23 拉到 28（L7 基础 16 + 妖刀 12）；F4 需要把出口血量从 13.5% 拉到 50% 以上（主要靠少 2 场消耗 + 普通怪 HP ×0.75，不是靠防御）；F5 的 15.5 回合缺口要靠 F4 的必掉稀有装备补，而不是继续加药（来源：D-42、D-43、D-50）。
3. **地图推荐每层宽高各 +4 格**（F1–F5：25×19 / 29×21 / 33×23 / 37×25 / 41×27，总面积 +36.7%）；保守值每层 +2 格（23×17 / 27×19 / 31×21 / 35×23 / 39×25，+17.6%）。不推荐 +6 格：会把 M1 的 2500 动作上限从 5/50 顶到约 20/50（估算），所有机器人基线要重跑。
4. **2500 动作预算对「走到楼梯 + 定点清怪」够用，对「100% 全清」不够**。推荐保留 2500 给 B1/S1，M1 改成「清 70% 房间」；若坚持全清口径，把 M1 上限提到 3200 并重跑 50 局基线（来源：D-42 的 1085.6 步与 5/50 顶格、D-43 的 F4 全清）。
5. **验收不看「爽」，看 6 个数字**：F3 出口血量 ≥65%、F4 出口血量 ≥50%、M1 到 F5 ≥8/50、M1 平均击杀 ≥20、B1 通关 32%–40%、F3–F5 普通怪中位击杀回合数 ≤4（定义见 §6）。

## 1. 「爽」在本作里指什么

### 1.1 四种爽感来源，本作选哪几条

| 来源 | 在本作里的具体表现 | 现状 | 本卡选择 |
| --- | --- | --- | --- |
| 数值碾压 | 伤害公式 `atk²/(atk+def)` 对攻击力是超线性的：atk 10→20 对 def 10，每回合伤害 5→13（2.6×）；20→30 时 13→23（1.77×）（来源：`js/systems/battle.js` 伤害公式 + D-41 表） | 已有，但 F3 后怪的血量涨得比玩家 atk 快 | **主选** |
| 爆装 | 拿到商店买不到、或当前层买不起的装备；本作已有 60/30/10 三档掉落与稀有龙牙剑（600 金币）（来源：平衡定档 §五、§六） | 有掉落，但所有装备都能在商店买到，「爆装」没有独占性 | **主选** |
| 解锁 | 新技能 / 新动作 / 新位移 | 当前只有火球一个技能，无技能树（来源：`js/data/skills.js` 仅火球） | **本卡不选**，需要新系统，放到设计案之后 |
| 身份变化 | NPC 认你、台词变化、结局评级 | 守夜人任务交付后有「已交付」状态；结局有 S/A/B/C/D 评级（来源：D-47、D-52） | **辅选**，成本低，用来给每层收尾 |

**为什么主选「数值碾压 + 爆装」**：这两条不需要新系统，只动怪物/装备/掉落表，能在现有 `Battle`、`Inventory`、`Shop` 里落地；「解锁」要新增技能树与按键，超出本卡「只出方案」的边界；「身份变化」只作为每层收尾的情绪反馈，不承担主要爽点。

### 1.2 「碾压」的可验收定义

本文把「碾压」定义成三个可测条件，后面所有表都用它：

1. **普通怪中位击杀回合数 ≤4（F3–F5）**：从踩到怪到怪死亡，玩家出手次数的中位数不超过 4。现状按面板 atk 与怪 HP 复算（估算）：F3 约 5、F4 约 7、F5 约 7。**不能用「2 回合内击杀」**：F1 的史莱姆 40 HP、目标 DPS 12，最少也要 4 回合；「2 回合」在本作的 HP 曲线下不可能达成，写进验收就是空指标。
2. **Boss 战玩家回合数 ≤10**：从战斗开始到 Boss 死亡，玩家行动次数不超过 10（来源：D-42 的 Boss 等价回合 7–25；F4 为 8、F5 为 8 已达标，F2 为 9）。
3. **出口血量 ≥65%（F3）/ ≥50%（F4）**：玩家走到下行梯时，HP 不低于最大值的 65%/50%（当前 F3 为 44.9%、F4 为 13.5%，来源：D-43）。

> - 面板 atk / def / maxHp 的基础值来自 `平衡定档.md` §四：atk = 10+(等级−1)、def = 5+(等级−1)、maxHp = 100+(等级−1)×10。
> - 装备加成：铁剑 +3、钢剑 +5（+3 强化 → 8）、锁链甲 +5、妖刀 +12、板甲 +8（+2 强化 → 10）、稀有龙牙剑 +16 / maxHp +10、稀有板甲 +16 / maxHp +10（来源：`平衡定档.md` §六）。
> - 强化口径：`Inventory.effValue` 每级 +10%、向上取整；妖刀 +12 强化到 +4 = ceil(12×1.4) = 17；稀有龙牙 +16 强化到 +5 = ceil(16×1.5) = 24；稀有板甲 +16 强化到 +2 = ceil(16×1.2) = 20。
> - F3 的「21→28」是本卡提出的目标，不是现状；现状 F3 面板 atk 为 23（D-34 的 L6 build），D-42 的 23.75 是「期望攻击」基线，不是面板值。28 = L7 基础 16 + 妖刀 12，在 D-40 的 L8 上限 41 之内。
> - F5 的 41/32/190 就是 D-40 §「路径 B」的可达上限（L8 + 稀有双件 +5/+2），不是新数值。

**F3 的具体补法（本卡建议）**：把「妖刀 +12」从商店 260 金币改成 F3 食人魔 30% 必掉（或密室宝箱必出），让 F3 出层 atk 从 23 到 28；对 def 5–9 的 F3 怪，每回合伤害从 17 提到 21（+24%，公式复算），普通怪中位击杀回合数从约 5 降到 4（估算）。若要把中位数压到 3，再叠加「F3 普通怪 HP ×0.85」（骷髅 70→60、食人魔 130→110、沃古尔 95→81、小恶魔 60→51，估算）。这一步不需要改伤害公式，只改掉落表与 HP 表。

**F4 的具体补法**：僵尸王击杀必掉「板甲 +8」（当前 40%，来源：平衡定档 §五；+2 强化后 def 10），把 F4 出口 def 从 16 拉到 22；对僵尸王（atk 24）每回合承伤从 14 降到 13（公式复算），只降 1 点——**防御不是 F4 的主要杠杆**。把出口血量从 13.5% 拉起来靠三件事：普通怪 11→9（少 2 场消耗）、F4 普通怪 HP ×0.75（大僵尸 240→180、面具兽人 150→112、死灵法师 135→101、南瓜怪 120→90，估算）、板甲必掉（省下 200 金币买甲钱，可多买 5 瓶大血或 2 瓶特大）。

**F5 的具体补法**：把稀有龙牙剑从「25% 三档」改成「F4 僵尸王必掉」或「F5 入口宝箱必出」，并保证稀有板甲到手，让 F5 进层达到 D-40 的可达上限 **atk 41 / def 32 / HP 190**；对 def 8 的巨龙每回合 34 点，260 血 8 回合击杀；按公式复算，8 回合承伤约 16×4 + 29×4 = 180，D-40 路径 B 算得约 199，2 瓶特大（300 点）可以覆盖。**不提出 atk 50**：41 已是 D-40 的可达上限，50 需要改成长上限，超出本卡范围。

### 4.1 现状与目标尺寸

| 层 | 现状（格×格） | 现状格数 | 推荐（+4） | 推荐格数 | 增幅 | 保守（+2） | 保守格数 | 增幅 |

| F1 | 21×15 | 315 | 25×19 | 475 | +50.8% | 23×17 | 391 | +24.1% |
| F2 | 25×17 | 425 | 29×21 | 609 | +43.3% | 27×19 | 513 | +20.7% |

| F4 | 33×21 | 693 | 37×25 | 925 | +33.5% | 35×23 | 805 | +16.2% |
| F5 | 37×23 | 851 | 41×27 | 1107 | +30.1% | 39×25 | 975 | +14.6% |
| 合计 | — | 2835 | — | 3875 | +36.7% | — | 3335 | +17.6% |

- 现状尺寸来源：`js/data/maps.js` 的 `Game.Data.MAPS.sizes`（5 层 `[21,15]/[25,17]/[29,19]/[33,21]/[37,23]`），以及 D-35/D-42 的任务卡。
- 推荐值取「宽高各 +4」：F1/F2 增幅大（补齐教学层太窄），F5 增幅小（终局不拖），总增幅 36.7%。
- 保守值取「宽高各 +2」：总增幅 17.6%，只够每层多放 1 个房间，不够做「大地图」的观感。

**为什么不是更大（+6）**：+6 的五层是 27×21 / 31×23 / 35×25 / 39×27 / 43×29 = 567/713/875/1053/1247 格，**单层增幅 46.5%（F5）到 80.0%（F1），总格数 4455（+57.1%）**；按 D-42 的 M1 1085.6 步与 D-43 的 5/50 顶格线性外推，顶格局会到约 20/50（估算），F4/F5 的行走本身就要 1800–2200 动作（估算），2500 预算基本失效。
**为什么不是更小（+0/+1）**：+0 没有变化；+1 只能多 1 行/列，房间数不变，玩家感知不到「地图变大」，也无法容纳新增的精英与宝箱。

### 4.2 单层步数与 2500 动作预算

| 指标 | 现状 | +4 推荐（估算） | +2 保守（估算） |
| --- | --- | --- | --- |
| M1 全流程步数（50 局均值） | 1085.6（来源：D-42） | 1420–1560 | 1200–1300 |
| F4 单层全清动作 | 700–900（估算，按 D-43 的 5/50 顶格反推） | 950–1200 | 820–1000 |
| 2500 上限顶格局 | 5/50（来源：D-43） | 12–18/50 | 6–9/50 |
| 结论 | 全清已经临界 | **全清不够，定点清够** | 全清仍紧张 |

**推荐口径**：
- B1/S1 保持 2500 动作上限不变，因为它们本来不追求全清（B1 只打 198 只怪 / 50 局，来源：D-40）。
- M1 若继续做「全清到 F5」指标，把上限提到 **3200**，并用同一批 50 个种子重跑；若不改上限，把 M1 目标改成「清 70% 房间 + 到 F5」，用「到达层数」而不是「全清」做验收。
- 两个口径只能选一个，不能一边说 2500 够、一边拿全清数据验收。

## 7. 风险与未验证项

- **BFS 单次耗时未实测**：本文按格数线性估算 <0.2ms，落地前应在 41×27 地图上实测一次。
- **+4 地图的 M1 全清动作是估算**：1085.6 步是现状 37×23 的实测，扩图后的 1420–1560 是按格数比例估算，必须用 50 局重跑替换。
- **F3 的 atk 28 目标是本卡提出的**：需要改掉落表，不能只改文案；如果用户不允许 drop-only 装备，F3 的爽点会退回现状。
- **F5 的目标是 41，不是 50**：D-40 的绝对上限是 atk 41 / def 36（epic 双件都 +5），路径 B（武器 +5 / 护甲 +2）是 atk 41 / def 32 / maxHp 190；atk 50 超过上限，需要改成长曲线，本卡不提出。41 对巨龙的 8 回合是 D-40 路径 B 的结论。
- **地图扩大与存档兼容**：地图尺寸变化不影响存档键与旧档字段，但旧档的 `pos` 可能超出新图边界，读档时仍需走现有 `resolveLanding` 兜底（来源：D-53）；本卡不改代码，落地时必须加一条旧档落点测试。
