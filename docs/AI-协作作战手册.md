> 适用范围：《AI勇者闯地牢》S3 界面定稿 → M8 内容 → M9 表现 → M10 AI 原生 → 收尾交付。
> 铁律：**话术必须按接收方 AI 的交互方式打磨**——给 Trae CN 的话术必须带项目内路径、用它的 Builder 模式、要求它先读文件再动手；给豆包的话术只给目标与现状，不重复计划。模板话术未经打磨不得直接使用（本条为豆包任务铁律，每次交付话术前我会按此检查）。

## 4. 每模块标准流程（六步循环）

1. **我写任务卡**：`docs/tasks/<模块名>.md`，含目标、文件范围、接口契约、效果判据、给你的**打磨后话术**。
2. **你传令**：把任务卡路径 + 我的话术原样发给 Trae CN（复制粘贴，不加工）。
3. **Trae 实现第 1 版**：写完告诉我"改动文件 + 自测结果 + 风险点"。
4. **我验证**：headless 跑 `preflight/verify_<模块>.html` + 审查代码 + 列"试玩检查单"。
5. **你试玩**：按检查单玩 3 分钟，把现象（含报错截图）带回；有问题我打回 Trae 第 2 版；循环。
6. **验收提交**：我裁定 PASS → 你让 Trae（或我用代理 git）commit + push → 我核对远程 HEAD → 记录到 PLAN.md。

## 5. AI 之间传递机制（关键纪律）

- 交接载体**只有三个**：`docs/tasks/`（任务卡）、代码注释（接口契约）、`preflight/`（验证页）。PLAN.md 是总纲。
- **你负责唯一的口头通道**：豆包 → 你 → Trae。不许 Trae 的对话历史污染我的判断，也不许我的上下文污染 Trae 的执行。
- Trae 说"这个做不了"→ 你原样带回 → 我改任务卡或换实现路径，你再去传。
- Trae 改了接口/命名 → 必须让它写进代码注释和任务卡回执，否则我验证时按契约打回。

## 6. 打磨后的话术库（按接收方定制，铁律执行）

> 用法：**对 Trae CN 说的话 → 用"Trae 版"**（带项目内路径、要求先读文件、要求结构化输出，匹配它的 Builder 模式交互习惯）；**对豆包（我）说的话 → 用"豆包版"**（只给目标与现状，方案我来出，不重复计划）。禁止把给一方的原话直接发给另一方。

### 场景 A：每模块开工（对 Trae CN 说——Trae 版）

> "请先读取项目根目录的 `PLAN.md`（重点是 §16-§19）和 `docs/tasks/<模块名>.md` 任务卡，再读取任务卡指定的现有文件（如 `js/core/render.js`、`js/data/config.js`）和相关接口契约注释，确认理解后按任务卡实现 `<模块一句话>`。硬性约束：保持原生 JS + Canvas 零构建，file:// 双击 index.html 可玩；不引入 npm、构建工具或付费资源；不修改 `window.Game` 命名空间和事件总线契约，除非任务卡明确允许。完成标准：①列出改动文件清单；②用内置终端跑任务卡指定的验证方式并贴结果；③说明你判断的剩余风险点；④若任务卡有实现不了的部分，直接说卡在哪、你试过哪几种办法、为什么不行——不要绕过或自己改方案。"

### 场景 B：Trae 卡住 / 报错（对 Trae CN 说——Trae 版）

> "把完整报错信息、涉及的文件路径和行号原样贴出来，说明你已经试过的做法和各自结果。不要猜测原因，不要改接口契约，不要为了过验证而删功能或写死数据。等你确认方案后再动手。"

### 场景 C：把 Trae 的疑问带回来（对豆包说——豆包版）

> "Trae 反馈：<原样粘贴 Trae 的回复>。它说做不了/改了方案，怎么处理？"（我会基于契约判断：换实现路径 or 打回 or 调整任务卡，然后给你新的 Trae 版话术）

### 场景 D：模块第 1 版完成，你试玩（对 Trae CN 说——Trae 版）

## 7. 现役任务卡样例（S3-1，下一个就做这个）

`docs/tasks/S3-1-rotjs-fov.md`：

- **给你的话术**：场景 A，`<模块名>` 填 `S3-1-rotjs-fov`，`<模块一句话>` 填"引入 rot.js 实现 FOV 视野迷雾，保持原有地图/移动逻辑不变"。

## 9. Trae CN 使用教程（细到点击，全流程）

### 9.1 启动与登录
1. 双击桌面"Trae CN"图标（或开始菜单搜索 Trae）打开。
2. 首次进入是欢迎页：右上角点**登录**，用手机号验证码（或抖音/字节账号）登录——免费 AI 额度跟随账号，不登录无法用内置模型。
3. 登录后进入主界面（左侧文件区、中间编辑区、右侧 AI 面板）。

### 9.2 打开本项目（关键：不要新建空项目）
1. 欢迎页点**打开文件夹**（英文界面为 Open Folder）；或顶部菜单 **文件(File) → 打开文件夹…**。
2. 在系统文件选择窗口里定位到：`D:\桌面\工作\人工智能大作业`，选中它（不要选里面的子目录）。
3. 点**选择文件夹**。
4. 弹出"是否信任此文件夹中的作者？"→ 点**信任（Trust / 是）**，否则 AI 无法读写文件。
5. 左侧文件树出现：index.html、css/、js/、docs/、PLAN.md、preflight/、README.md 等，即打开成功。

> ⚠️ 禁止：欢迎页"新建项目"向导创建空项目——会让代码与现有仓库分离，我无法验证，所有任务必须在这个已存在的文件夹里做。

### 9.3 界面认识（一次看全）
- **左侧边栏从上到下**：①文件树（资源管理器）；②搜索；③源代码管理（git 分支图标，提交/推送在这里看）；④运行与调试。
- **底部状态栏**：模型选择区（点击可切换模型）、**终端按钮（Terminal）**——所有 git 和验证命令在终端里跑。
- **右侧 AI 面板**：对话输入框；顶部有**模式开关**——`对话(Ask)` 只问答不写文件，`Builder/Agent` 能读写文件跑命令。**干活必须用 Builder/Agent 模式**。

### 9.4 选择模型与模式（每次开工前确认）

1. AI 面板输入框上方点模型下拉，当前账号可用的内置模型（**以你界面实际列表为准**，2026-10-28 截图确认）：
   - **Auto Mode**：让 Trae 按任务自动选模型——任务卡没指定时**日常首选**。
   - **Seed-Code（专属补贴 0.06x）**：代码专用模型、最省钱——**编码/改代码任务首选**。
   - **Seed-2.1-Pro-0915（0.80x）**：推理最强——**复杂模块手动切**：Boss 二阶段（M8-2）、Q-learning 动态难度（M10-1）、LLM 内容生成（M10-2）。
   - **Seed-2.1-Turbo（专属补贴 0.20x）**：快且便宜——简单生成/常规问答。
   - **GLM-5.3-Flash（0.08x）**：便宜备选。
   - 规则：任务卡写了"用 Pro"才切 Pro；没写一律 Auto Mode 或 Seed-Code。
2. 模式开关切到 **Builder / Agent**（能真正改文件；Ask/对话模式只问答不写文件）。
3. 确认左下角/面板顶部显示当前项目路径是 `D:\桌面\工作\人工智能大作业`，不是别的目录。

### 9.5 让 AI 干活的标准操作
1. 把场景 A（Trae 版）话术**完整粘贴**进 AI 输入框，回车。
2. 观察它第一步是否"读文件"（会在输出里显示 Reading 或引用文件路径）；若它直接开写且没读文件，补一句："先读取任务卡和指定文件，确认契约后再动手。"
3. 它完成后若只说"已完成"没给清单，追问："按任务卡输出：改动文件清单、验证结果、风险点。"
4. 要看代码：在左侧文件树点开对应文件，中间编辑器查看/可手动改。

### 9.6 在 Trae 里跑验证与 git（内置终端）
1. 底部点**终端**图标（或快捷键 `` Ctrl+` ``）打开内置终端。
2. 验证页：`cd /d D:\桌面\工作\人工智能大作业` 后按任务卡给的命令跑（Edge headless 命令我会写进任务卡，原样复制）。
3. 提交推送：直接用场景 E 的三条 git 命令（含代理参数，原样复制执行）。
4. 查看提交结果：左下角**源代码管理**图标 → 看改动文件列表 → 或让 AI 在终端贴 `git log --oneline -5`。

### 9.7 Trae 避坑清单（贴在你电脑旁）
- 不在 Trae 里点"新建项目/New Project"——永远打开现有文件夹。
- 不让 Trae 装 npm 包、跑 `npm install`、建 build 目录——零构建是硬约束。
- Trae 报错只给一句"失败了"时：用场景 B 话术要求它贴完整日志与文件行号。

## 11. DeepSeek 的位置与使用（明确：它不在开发链路里）

**结论：开发链路只有豆包（指挥）+ Trae CN（执行），没有 DeepSeek。** DeepSeek 是**游戏运行时**的一个组件——游戏里的 AI NPC 大脑（T 键对话），不是开发 AI。

### 11.1 它在哪被用到
- **M5 已接入**：`js/systems/npc.js` 调用 DeepSeek API 生成 NPC 回复；无 Key/断网自动降级为本地预设对话（游戏仍可玩）。
- **M10-2 将扩展**：任务文案、商店描述、随机事件由 LLM 动态生成，无 Key 全部降级。
- **作用域**：只在玩家玩游戏时被调用；开发过程中它完全不参与。

### 11.2 你需要做的配置（一次性，可选）
1. 注册：`platform.deepseek.com`（手机号注册，新用户有免费赠送额度）。
2. 创建 API Key：控制台 → API Keys → 创建 → 复制 `sk-` 开头的 Key。
3. 填入项目：`js/data/config.js` 里的 `deepseekKey` 字段（现在留空=离线降级模式，游戏一切正常）。
4. 测试：双击 `index.html` → 按 T 打开 NPC 对话 → 输入"你是谁"——有加载后生成式回复即在线成功。

### 11.3 关键词与话术（DeepSeek 相关，只有这些）
- **API 模型名**：`deepseek-chat`（在 npc.js 里已写好，不用你改）。
- **游戏内测试输入**："你是谁"、"这个地牢是怎么回事"（看是否出现生成式回复）。
- **你不需要对 DeepSeek 说任何开发话术**——它只被游戏代码调用；开发沟通只走豆包↔Trae。
- 若 NPC 对话报错（网络/额度）：把游戏控制台报错原样带回给我（场景 C），由我判断是 Key 问题还是代码问题。

### 11.4 排期提醒
- 现在（S3 阶段）：**不需要动 DeepSeek**，config.js 留空即可。
- 到 M10-2 时：任务卡会明确写"在 config.js 填 Key 后验证动态文案"，那时你按 11.2 配置即可。
