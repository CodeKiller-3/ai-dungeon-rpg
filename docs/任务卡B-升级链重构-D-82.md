> 性质：**数值 + 成长曲线**。这是本阶段唯一允许改数值的卡；但必须先过 A（系统感）的只读回归，避免两件事混在一起。

## 1 需要先拍板的取舍：刀 vs 等级

**判断：分工，不合并、不砍。**

- **刀保下限**：F1–F4 每层一把、必掉、自动装备（`main.js:503-545`、D-72）。它保证“只要推进，就不会掉队”，是 B1 48% 的来源；砍掉它，F5 会直接变成随机墙。
- **等级开上限**：只在 **L10** 给一次“系统突破”，+9 atk / +4 def / +20 maxHp。B1 平均 L4.8、S1 L4.3、G2 L8.26，够不到；M1 L10.33，够得到。于是“练了→碾压”只发生在真正清到 F5 的人身上。
- **这不是“两边都加常驻攻击”**：刀不加，等级也不每级加；只有 L10 一次。两者不是两个平行来源，而是“地板”和“天花板”。
- **如果必须二选一**：留刀，砍等级。因为刀是 B1 48% 的物理基础，砍了会毁掉 45–52；但那就等于承认“升级”只是叙事，和主题相悖。所以不推荐二选一，推荐分工。
- **不建议合并成“武器随等级成长”**：见 §3 候选 C，它要么只是把现有 22 攻延后（不产生新碾压），要么是“候选 A + 对 B1 的前期削弱”，严格劣于 A。

> 一句话：**刀负责“我不会掉队”，等级负责“我终于能碾”。**

## 3 候选 B：F5 难度前置 + 层内突破

### 3.1 具体改什么

- `js/data/monsters.js`：把 F5 普通怪 HP 抬到“进层 4 回合”：
  - 大僵尸 88→130，死灵法师 100→145，蒙面兽人 98→135，天使 135→150（约 +40%~+50%）。
- 在 F5 50% 位置（精英后）给一次“突破”：+9 atk / +4 def / +20 hp（与 A 相同的量）。
- 目标曲线：F5 进层 4 回合 → 突破后 3 回合（不是 2）。

### 3.2 玩家会看到什么

| 层 | 变化 |
|---|---|
| F3 | 不变 |
| F4 | 不变 |
| F5 | 进层普通怪 **4 回合**（更难），精英后 **3 回合**；不是“4→2”的碾压 |

### 3.3 为什么“4→2”在这个公式下做不出来

要让 F5 进层 4 回合，HP 必须 > 3 × 当前伤害：
- 大僵尸 3×39=117 → 至少 118；死灵 3×42=126 → 127；蒙面 3×40=120 → 121；天使 3×42=126 → 127。
- 突破 +9 后 atk 56，伤害 44/50/49/51；要把这些 130/145/135/150 HP 压到 2 回合，需要单发 **65/73/68/75**，即 atk **74/78/75/80**。
- 也就是需要 **+27~+33 atk**，不是 +9。这样的跳变会让 F5 后半段和 Boss 直接失去意义。

**结论：** 候选 B 只能交付“4→3”，交付不了“4→2”；如果要 4→2，必须给 +27~+33 atk，那已经是另一个游戏。

### 3.4 会推翻什么 / 风险

- D-66 的 F5 HP/回合、D-67 的 B1、D-68/69 的 F5 曲线、D-72 的 Boss 回合、D-73 的全矩阵都要重跑。
- B1 的 F5 精英胜率只有 **32%**（D-69 §4.6）；也就是说 68% 的 B1 到达局会面对更硬的 F5 却拿不到突破。B1 很可能 **跌破 45%**，S1 可能直接 0/50。
- 要救 B1，只能把 F5 HP 降回去（headroom 消失）或提高救援（改变 D-50 定档）。**这是自我抵消的。**
- **判断：不要做。** 它不是“改了会变好”，是“改了只是更硬，而且大概率毁掉 45–52”。

## 4 候选 C：武器共鸣 / 等级门槛

### 4.1 具体改什么

- `js/data/items.js` 给五把精英刀加 `masteryLevel`；`Inventory.effValue`/`recalcEquip` 用“未解锁值/解锁值”；物品页显示 `攻击 16（Lv.10 解锁 22）`。
- 例：F5 烬牙在 L10 前 = 16，L10 后 = 22；F4 守夜在 L9 前 = 13，L9 后 = 16。

### 4.2 玩家会看到什么

| 层 | 变化 |
|---|---|
| F3 | 若 mastery L8，G2/M1 解锁，B1 不解锁 |
| F4 | 若 mastery L9，M1 解锁，B1 不解锁 |
| F5 | B1（L6）拿到 16，比当前 22 **更弱**；M1（L10）拿到 22，**和当前一样**；F5 仍然 3→3 |

### 4.3 为什么它不解决问题

- 如果解锁值 = 当前值（22），那只是把现有力量延后：B1 被削，M1 没变强，F5 仍然 3→3。**没有新的“碾压”。**
- 如果解锁值 > 当前值（比如 31），才可能到 56 atk；但那就是“候选 A 的 +9”外加“B1 在 L10 前少 6 攻”。A 严格优于 C：A 不动 B1，C 先削 B1 再给同样的上限。
- 结论：**C 被 A 支配，不要做。**

### 4.4 会推翻什么 / 风险

- D-72 的 A1/A2/A6（有效攻击/最大跳/不低于商店）、D-73 的面板、D-66/67/68/69/72 的回合、B1 都可能跌破 45。
- UI 还要处理“未解锁/已解锁”的比较与售卖价，复杂度高，收益为负。
- **判断：不要做。**

### 5.1 推荐：候选 A，并且先做“分工”拍板

- **拍板：分工。** 刀保 F1–F4 的下限；等级在 L10 开一次上限。两者不是两个平行的加攻来源。
- 为什么不是合并：候选 C 是唯一真正的“合并”，但它要么不产生新跳，要么先削 B1；严格劣于 A。
- 为什么不是砍一个：砍刀会毁掉 B1 48% 的物理基础；砍等级会让“升级”永远只是叙事。分工是唯一同时保住“确定性下限”和“主题上限”的做法。
- 如果只能留一个：留刀。但要接受“升级”只是叙事，这和课程主题相悖，所以不推荐。
