## 零、开演前 30 秒

1. 双击 `index.html`（`file://` 直接可玩，零构建、零依赖）。
2. 若本机有旧档：首屏「设置 → 清除存档」，按 Enter 键 两次，保证从「无档」状态开演。
3. 建议窗口 1280×800，浏览器缩放 100%。

开场一句话：「这是《当前标题》——零构建的像素地牢 RPG，四层 AI：A\* 寻路、行为状态机、大模型 NPC、Q-learning。」

| 步 | 按键 | 预期画面 | 对应验证页 |

| S02 | 按 方向键 移动；首次引导层按 Enter 键 关闭 | 进入第 1 层（共 5 层）：迷雾圈、顶部 HUD（HP/MP、金币、楼层、击杀进度）、BGM 自动切到探索 | `verify_smoke`、`verify_s3_1`、`verify_s3_2`、`verify_m1` |
| S03 | 按 方向键 跟着**屏幕右侧边缘的箭头与步数**走 | 见到灰色提灯人「守夜人·洛恩」（实体 NPC，固定在第 1 层主路 72% 处）；HUD 右侧显示「守夜人 N 步」，方向由 BFS 实测，按它走 50/50 可达（`verify_d55`，平均 19.5 步） | `verify_d47`、`verify_d55` |

- 难度定位：机器人 B1（不打怪、直奔 Boss）**14/50**；没看过代码的真人首次通关估计 **40%–55%**。

## 六、演示失败时的兜底

| 现象 | 处理 |
| --- | --- |
| 开场没有首屏 | 地址栏补 `?skipmenu=0` 刷新；仍无则看控制台是否有脚本加载失败 |
| 找不到守夜人 | 看**屏幕右侧边缘**的箭头与步数，跟着走即可；接了任务后 50 个种子全部可达（`verify_d55` A 组，平均 19.5 步） |
| 没遇到怪 | 换一条岔路；怪物按层概率表生成，不保证直线遇到 |
| 火球没反应 | MP 不足或冷却未结束，换按 1 键 普攻；提示条会说明原因 |
| 演示机没有存档 | S10 先做一次「返回主菜单」，再演示「继续游戏」 |
