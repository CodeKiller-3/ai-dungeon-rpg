**现象**：`Shop.buy(id)` 只查 `ITEMS[id]` 和金币，不查 `getStock()`；精英刀 `price=sell=0`，救援剑有价（90/45）但也不在货架。证据：[shop.js#L81-L95](file:///d:/桌面/工作/人工智能大作业/js/systems/shop.js#L81-L95)、[items.js#L90-L99](file:///d:/桌面/工作/人工智能大作业/js/data/items.js#L90-L99)、[items.js#L239-L242](file:///d:/桌面/工作/人工智能大作业/js/data/items.js#L239-L242)。

**现状**：正常 UI 只展示 `getStock()`，所以玩家点不到；只有手敲控制台才能 `Shop.buy('elite_fang_5')` 白拿精英刀（或花 90 买救援剑）。不是可玩性 bug。

**为什么是 P3**：交付前加固成本低；如果老师/同学喜欢开控制台，这会变成“精英刀不是 drop-only”的质疑。

**改正方案**：`buy` 里加 `getStock().some(x => x.id === id)` 校验，并显式拒绝 `item.elite`/`item.rescue`；或者只做前者，把“不可买”从 UI 约束变成 API 约束。

**怎么验证**：`verify_c02` 仍 PASS；新增负例：`Shop.buy('elite_fang_5')` 返回 `ok:false`。

#### P3-4 根目录残留 `debug.log`

**怎么验证**：根目录 `git status` 不再出现该文件；压缩包内无 `*.log`。

## 7. 我认为不该改的

下面这些看起来像“缺陷”，但它们是刻意的取舍。下一轮如果有人把它们当 bug 改掉，会破坏已经定档的体验。

1. **320 窄屏回退纵置战斗**。当前 D-94 默认横置，但 `W<720` 或宽高比不足时回退纵置；320 宽七格指令条横置会被挤成 36px 一格。证据：[render.js#L834-L846](file:///d:/桌面/工作/人工智能大作业/js/core/render.js#L834-L846)。不要为了“统一横置”把 320 也强行横置。
2. **精英刀不可强化**。`Inventory.upgrade` 明确把 `elite` 排除，原因写在注释里：它随等级成长，再吃强化卷轴会双倍成长。证据：[inventory.js#L115-L118](file:///d:/桌面/工作/人工智能大作业/js/systems/inventory.js#L115-L118)。不要“补上”精英刀强化。
3. **B1 3/50、S1 0/50**。B1 是不打怪直奔 Boss，S1 是纯逃跑；它们低胜是设计目标，不是平衡失败。证据：[平衡定档.md#L636](file:///d:/桌面/工作/人工智能大作业/docs/平衡定档.md#L636)、d94-p82 JSON。不要为了让四策略“好看”去 buff 这两条路线。
4. **精英刀不可卖、不可买、不可枚举**。`price=sell=0`、`Shop.sell` 拒绝、`defineProperty` 不可枚举，是 D-71 的 drop-only 设计。证据：[items.js#L84-L105](file:///d:/桌面/工作/人工智能大作业/js/data/items.js#L84-L105)、[shop.js#L102-L103](file:///d:/桌面/工作/人工智能大作业/js/systems/shop.js#L102-L103)。不要把它们加进商店或改成可卖。
5. **龙血 350 + 龙威 + 二阶段**。350 是为了让最终 Boss 不被 L11 玩家 8 回合内打穿；G2 15 回合、B1 13 回合是时间杠杆的代价。证据：[monsters.js#L68-L99](file:///d:/桌面/工作/人工智能大作业/js/data/monsters.js#L68-L99)、[平衡定档.md#L640-L653](file:///d:/桌面/工作/人工智能大作业/docs/平衡定档.md#L640-L653)。不要为了“Boss ≤10 回合”把 350 改回 260。
6. **五把刀基础 3/6/9/11/12 + 分级成长**。这是 D-84 的核心，不是把旧 8/12/16/22 写错。证据：[items.js#L90-L99](file:///d:/桌面/工作/人工智能大作业/js/data/items.js#L90-L99)、[README.md#L47](file:///d:/桌面/工作/人工智能大作业/README.md#L47)。不要按旧文档“修正”回固定值。
7. **只做键鼠、不做触屏**。这是当前范围取舍；320 窄屏验证的是桌面窗口，不是手机。不要为了“移动端”在交付前临时加 touch 层。
8. **200 局 = 4×50 固定种子**。这是可复现回归，不是“随机抽样”；不要改成随机种子或只挑赢的局来“优化”数字。
