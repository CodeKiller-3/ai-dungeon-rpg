## 1 目标与不变量

### 1.1 交付三件事

1. **等级是主力量**：同一把刀，等级越高越强；面板主涨幅来自等级。
2. **刀是形状**：每把刀的成长斜率/断点/附带属性不同（§3.1），不是五条平行线。
3. **突破在 F5**：L11 的 +12/+7/+30 落在 F5 清怪尾段，正对“站在巨龙面前”。

### 1.2 不变量（违反即打回）

| 不变量 | 判定 |
|---|---|
| 固定 5 层 | `MAPS.floors===5` |
| 存档键 `ai_dungeon_rpg_save_v1` 只加字段不改名 | 本卡**不改 `save.js`**，刀强度由 `level` 推导 |
| 买价 > 卖价 `sell=floor(price/2)` | 精英刀 `price=sell=0`，不参与；商店价一个不动 |
| 原生 JS 零构建、`file://` 可玩 | 只改 §2.1 的 8 个路径 |
| 不靠放宽断言消 FAIL | §5 逐页判定；§6.3 区分“判据”与“页面” |
| 文档不写未实现/未实测数字 | 新数字全部带标注，验收前不得当现状 |

### 1.3 不做

暴击/吸血/新状态、转生/巅峰、第 6 层、同伴、改伤害公式、改 `GROWTH_LEGACY`。
