# 系统口吻文案全案（主题：《地牢：我独自升级》）

> 性质：**只出文案，不改代码**。本文档给出的每一条都标了 `文件:行`、原文、替换文与"不改的东西"。
> 执行端照本文改字符串即可，不需要再判断语气。
> 世界观前提：全游戏只有一个活人（F1 守夜人·洛恩）；F2 之后不再有人开口，所有提示由「系统」发出。

## 0 三条硬约束（先看）

1. **不出现对话框式交互**：新文案不用 `「」`、不用"某某说"、不用问答句式。系统只发**通知**，不回应玩家。
2. **不引入任何"人"**：不用 `递 / 塞 / 拉 / 扶 / 按回 / 拽起 / 陪你 / 帮你` 这类动词；系统只做 `检测 / 注入 / 划入 / 解析 / 介入 / 评估`。
3. **不做鼓励**：不写"先活着""别硬撑""活着下去比什么都强"。系统只报事实与剩余额度。

配套的机械约束（沿用既有验证口径，不要踩）：
- 不用 `！`（D-20 D1 只允许死亡/胜利/升级三类用感叹号；本文所有新句一律用 `。`）。
- 不用裸词「强化」（D-20 C2）；需要表达成长时写 `突破 / 解析 / 装备`。
- 不写死 `生命恢复至 X%`：这个尾巴由 `adaptive.js:217` 与 `:248` 追加，写进 `MSG` 会重复。
