# D-50 平衡定档 —— 数值这条线的最后一张

> 性质：**收口卡**。此后除非发现可利用的 bug，不再动怪物 / Boss / 掉落 / 经验 / 价格 / 救援量。
> 本卡的目标不是把数字调好看，是把结论钉死，让 README、讲稿、演示可以说得出口。

## 一、做法

1. 先用 `d44` 的逐回合实测日志把 F5 的 20 局阵亡逐局拆开（回合 / 药 / 输出三本账）。
2. 只动"药 / 回合"这一侧：在 `adaptive.js` 里准备 12 种 F5 救助形态，逐一实测（同种子 1001–1050、
   maxActions 2500、B1）。
3. 选达标且不过界的一种定档，写进 `docs/平衡定档.md`。
4. 把"文档 ↔ 源码"的比对做成机器断言（`verify_d50` E 组，25 项）。

## 二、F5 拆解结论

| 口径 | 数值 |
| --- | --- |
| D-49 口径下 F5 触发次数 | 38（F5 一级 18 + 三级 20），分布在 20 局 |
| 平均还差回合 | 15.5（中位 12.5，范围 4–34） |
| 平均 Boss 剩余血量 | 142.6（合计 2852） |
| 平均折算治疗 | 338（≈4.2 瓶大血瓶 ≈169 金币，超 150 上限 13%） |
| 需要 ≥160 金币药量的局 | 17/20（85%） |
| 每回合输出 / 承伤 | 10.3 / 20.7（"1 点输出要换 2.0 点治疗"） |

**结论：F5 不是药不够，是回合不够；回合不够的根因是输出不够。** 因此本卡**没有**往攻击力方向调任何数值。

## 七、必答

**1. F5 那 38 次，差的是回合、药还是输出？**
回合。20/20 局都还需要额外存活回合才能把 Boss 打死（平均 15.5 回合）；Boss 平均还剩 142.6 血，
折算 338 点有效治疗（4.2 瓶大血瓶 / 169 金币），已经超过 150 上限 13%；85% 的局所需药量 ≥160 金币。
药只是"买回合"的价钱，输出才是缺口来源（每回合打 10.3、挨 20.7）。

**2. 你选了哪种救助形态，为什么是它？**
"一次原地复活"（仅 F5 第 1 次死亡，60% 血，保留怪物血量，不发物品）。原因是药水侧 8 种形态
全部 10/50，只有"不重置怪物血量"能真正改变结果；而两次原地复活会到 21/50、把 F5 变成形式，
所以只保留一次。

**3. 最终通关率多少？最接近的三局各差什么？**
14/50（28%），达标（≥13）。最接近的三局：1013 差 3 回合 / 19 血 / 1 瓶大药（卡在"单局 2 次"名额，
金币还剩 90）；1046 差 8 回合 / 87 血 / 2 瓶；1008 差 8 回合 / 118 血 / 3 瓶。

**4. 定档文档里最难写的一条结论是什么？**
"F5 的缺口是回合/输出，不是药"。它意味着**在 150 金币与"不改伤害公式"两条约束下，F5 本来就该
有 30% 左右的人过不去**——这不是没调好，而是设计选择；写下来等于承认前几张卡（D-44/D-45/D-46）
反复调补给都没能改变结论，只能改变"差多少"。

**5. 没看过代码的真人大概多少通关率？依据？**
40%–55%。依据：B1 是不打怪、直奔 Boss 的极端打法（50 局仅 198 只怪、262 步，进 F5 平均 55 血、
4 瓶大药）；真人会先清怪升级（升级回满血）并把 F1–F4 的 470 金币换成 7 瓶大药，
按第十节恒等式，F5 平均 338 点的治疗缺口能被补掉大半，加上 F5 落点 2 瓶特大血瓶（300 点），
单场有效血量从 200–224 提到 550 以上。
