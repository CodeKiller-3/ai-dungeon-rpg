# D-43 血量经济审计 —— 血到底花在哪了，赚的够不够花

- 日期：2026-11-12
- 性质：测量 + 补给侧修正（只改回血/补给；怪物 hp/atk/def、Boss、伤害公式、楼层结构、存档键、买卖价一律未动）
- 依据：D-42 实测 M1 有 23/50 死在 F3 普通怪（食人魔 9、食尸鬼 7、骷髅 5、小恶魔 3），F3 出口 HP 均值只剩 **12.76**（8%），进 F4 等于带着尸体走。

## 0. 结论（一句话）

**不是密度问题，是补给问题。** M1 全程承伤 26,942（50 局合计）里 85.6% 来自普通攻击，怪的种类没有异常；真正断掉的是 F2–F3 的药水供给：改前 F3 每层平均只新得 **0.28 瓶**，承伤/回复比 **1.853**。把补给线放宽后，M1 到 F4 从 6/50 抬到 **27/50**，F3 出口 HP 12.76 → **72.30（44.9%）**，但 M1 到 F5 仍是 **0/50**——拦住它的是 2500 动作预算，不是血。

## 1. 口径

- 采样：M1 / S1 / G2 三组，种子 1001–1050，`maxActions=2500`，与 D-37/39/40/41/42 完全一致。
- 血量账：在"数值已经发生之后"记录每一次 HP 增减（不参与计算）：
  - 承伤来源：`monster_attack`（普攻）、`boss_skill`（二阶段技能/吐息）、`status:poison`、`status:bleed`、`trap:spike`（地刺）、`adjust:maxhp`（换装上限回落导致的钳制）。
  - 回复来源：`levelup`（升级回满）、`potion`（手动用药，战斗内/外同一口径）。
  - 每层：`hpIn + healTotal − damageTotal − hpOut = 0`，致死溢出按实际掉血记，**误差必须为 0**。
- 药水计数只算"回血药"（`effect.hp > 0`）；"新获得"= 层末库存 − 层初库存 + 本层消耗，含掉落/宝箱/商店/任务。

## 9. 五问

1. **血主要掉在哪？按来源给前三位和占比。**
   全程：**普通攻击 85.6%**、Boss 技能 4.9%、陷阱 4.7%（其后流血 3.5%、毒 1.2%）。
   只看 F3：普通攻击 **92.2%**、陷阱 3.4%、流血 2.6%；按怪是**食人魔 54.4%**、沃古尔 20.3%、骷髅 11.5%。
   只看 F2：普通攻击 82.8%、独眼酋长技能 10.3%、陷阱 2.9%；按怪是酋长 30.7%、兽人战士 25.0%、萨满 20.0%。
2. **是密度问题还是补给问题？一句话结论。**
   **补给问题**：F3 改前每层只新得 0.28 瓶药、承伤÷回复 1.853；怪的种类和伤害结构没有异常（92% 是普攻），把药水供给抬到 2.65 瓶/层后同一批种子 F3 出口从 8% 回到 44.9%。密度只报数，未动。
3. **补给放宽到多少？护栏有没有被顶到上限？**
   每层新得药水：F1 2.06 / F2 1.92 / F3 2.65 / F4 1.52（平均 2.08，上限 3）；单局最多喝 **14** 瓶（上限 15）。两条护栏都**没有被顶穿**，但 14/15 已经接近上限，后续再放宽会先撞"单局 15 瓶"。
4. **改完 M1 的死层和死因变成什么样？**
   死层：F2 21→**7**、F3 23→**16**、F4 6→**27**（另有 5 局 F4 动作上限、活着的 110–144 HP）。
   死因（按最后一击的怪）：**大僵尸 10、食人魔 10、僵尸王 10、独眼酋长 7、骷髅 3、沃古尔 3、蒙面兽人 2**。集中度从"F2 酋长一家独大"变成"F4 三种怪平摊"。
5. **现在离"通关"还差什么？差多少？**
   差 **F4 这一层**：27 局进 F4，22 局死（承伤 447/局 vs 回复 355/局，比值 1.258），5 局活着但 2500 步用完。要再往前，需要（a）F4 的补给再高一档——但会先撞单局 15 瓶上限；（b）M1 不再"全清"F4，省下动作下楼——属于 bot 判据，本卡不能动。巨龙已能被 S1 打到剩 51.2%，但 0 杀；离通关还差"活着走出 F4"这一步。
