- 基线：`a92e6a3`（回归 74/74）
- 授权范围：**只解冻两项**——① 伤害公式 `max(atk-def,1)`；② 第 5 层最终 Boss（`dragon`）的数值。
- 明确不动：其它 17 种怪数值、Boss 二阶段机制（enrage 参数）、楼层数、物品价格与 `sell=floor(price/2)`、商店货架、F1~F4 期望强度、存档结构。

## 1 病根（先量）

旧式 `max(atk-def,1)` 是纯减法，两个后果都能用数字复现：

1. **免疫点**：玩家 def ≥ 怪物 atk−1 时，该怪恒打 1 点。F5 玩家典型 def=26，而 F5 普通怪 atk 只有 23~28，于是 `big_zombie/necromancer/masked_orc` 全部只能打 1 点，`angel` 打 2 点。
2. **层间倒挂**：按各层权重与"该层典型 def"折算的期望受击伤害是
   `F1=1.00 F2=1.50 F3=1.75 F4=3.35 F5=1.25`——**第 5 层比第 4 层更软**。
3. **Boss 比小怪还弱**：旧 `dragon` = `hp150 / atk18 / def8`，而同层普通怪 `angel` = `hp180 / atk28`、`big_zombie` = `hp240 / atk26`。最终 Boss 在 atk 与 hp 两项上都输给普通怪。

> 注：怪物打玩家走 `damage()`，玩家技能走的是另一条"倍率版"减伤（`max(round(atk×倍率)-def,1)`）。本次只解冻前者；理由与影响见 §5。

## 2 候选公式（3 版）与对比

三个候选都满足"实数曲线严格递减"，差别在**减伤形状**与**低层是否变硬**：

| 候选 | 公式 | 减伤含义 | 实数最大单步降幅（def 5→45，atk 6~40） |
|---|---|---|---|
| C1（采用） | `max(1, round(atk²/(atk+def)))` | 减伤率 `def/(atk+def)`，攻击越高越难被完全防住 | 8.3%（atk6）~2.2%（atk40） |
| C2（否决） | `max(1, round(atk×100/(100+4×def)))` | 固定斜率线性减伤，`def` 每 +1 减 4 点等效攻 | 3.2% |
| C3（否决） | `max(1, round(atk×30/(30+def)))` | 固定分母减伤（def=30 时减半） | 2.8% |

玩家模型：等级 2/4/6/8/10，武器 atk 3/8/8/12/12，护甲 def 3/5/6/8/12 → `atk 14/21/23/29/31`、`def 9/13/16/20/26`、`maxHp 110/130/150/170/190`。

|---|---|---|---|---|---|
| F1 | 9 | 1.00 | **3.25** | 5.25 | 5.70 |
| F2 | 13 | 1.50 | **6.75** | 8.75 | 9.05 |
| F3 | 16 | 1.75 | **7.30** | 8.85 | 9.85 |
| F4 | 20 | 3.35 | **11.75** | 12.15 | 13.20 |

- C1：`3.25 < 6.75 < 7.30 < 11.75 < 12.90`，五层单调递增，且修掉了旧的 F4>F5 倒挂。
- C2：F4=12.15 与 F5=12.65 只差 0.5，第 5 层几乎不涨；F1=5.25 是 C1 的 1.6 倍。

### 2.2 `def 5→45` 逐点曲线

- **实数曲线**（未取整）对三个候选都严格递减：C1 在 `18 只怪 atk × def 5→44` 共 720 个相邻点上差值全部 <0，无常数段。
- **无断崖**：单步最大降幅 C1=8.3%、C2=3.2%、C3=2.8%，均远低于 20% 阈值。
- **无免疫**：任意 atk/def 下伤害 ≥1；每层普通怪在该层典型 def 下的伤害区间

### 2.5 选定 C1，否决 C2 / C3

**选 C1 的理由**
1. F1 最温和（3.25，C2=5.25 / C3=5.70），符合"F1 不变得过难"。
2. 五层单调递增（3.25→12.90），把旧的 F4>F5 倒挂修正为 F5 最难。
3. 任一层在该层 def 下都不出现"全部打 1"；防御仍有意义（天使 24→15→11 对应 def 5/26/45）。
4. 玩家侧击杀回合基本不变，Boss 侧的变化不会被玩家 DPS 意外放大。

**否决 C2**：线性减伤在低 def 段偏硬（F1=5.25），且 F4/F5 只差 0.5，第 5 层几乎不涨，"越深越难"表达不出来。
**否决 C3**：固定分母导致 F1 最硬（5.70），低层惩罚最重；且 atk 6 的整数平台（21）比 C2 还长。

> 三版都满足"无常数段 + 无免疫 + 无断崖"；C2/C3 是**权衡上不如 C1**，不是不合格。

### 3.3 与二阶段配合：不是必死，也不是必过

F5 典型 build（atk31 / def26 / hp190）：

- 玩家每回合对 Boss：`round(31²/(31+8)) = 25` → 击杀 `ceil(260/25) = 11` 回合。
- Boss 狂暴前每回合：`round(32²/(32+26)) = 18` → 不吃药可挨 `floor(190/18) = 10` 下。
- 狂暴后（hp≤130）：atk `round(32×1.5)=48` → 普攻 `round(48²/(48+26)) = 31`；吐息 `round(48×1.4)=67` → `round(67²/(67+26)) = 48`，30% 概率触发。
- 结论：前 6 回合能扛住，后 5 回合必须靠药水/护盾；不是"见面秒"，也不是"站着过"。数值上"11 回合击杀 / 10 下可挨"留出了用药与技能的操作空间。

> **D-40 标注（2026-11-12，不改上方任何数字）**：本节"F5 典型 build（atk31 / def26 / hp190）"对应的是 L10 模型（`10+9+12`、`5+9+12`、`100+9×10`）。按 `expToNext(level)=60×level`，L10 需累计 2700 经验；全图 45 只怪最多 1748–1984，加全部任务奖励 640 也只有 2624，**L10 在任何种子与玩法下都不可达**；且 `hp190` 首次出现于 L8（需两件最大生命装备），那一刻 atk/def 至少已是 33/28，与 31/26 不同时。因此本节只作为"若该状态存在"的解析参照，**不构成可达性结论**；真实可达上限与差距见 `docs/tasks/D-40-成长上限审计.md`。

五层期望强度算法是 `Σ rate × (atk + hp/10)`，只读 `MAPS.enemyTable`；`dragon` 从 P2-4 起就**不在普通表**（由 `MAPS.bosses` 单独注入 1 只）。所以：

- 旧值 → 新值：`F5 = 44.1 → 44.1`（**改动 0 处**）。
- `selfcheck.js` 的 DC-04 基线 `11.125 / 20.125 / 23.75 / 36.85 / 44.1` **一个数都不用动**。
- 卡面"改 Boss 会改 44.1"的前提不成立：那条链只在 Boss 出现在 `enemyTable` 时存在。这里如实记录，而不是为了让卡面成立去动基线。

## 5 范围边界：玩家技能仍走"倍率减伤"

`js/systems/battle.js` 里玩家技能伤害是 `max(round(atk×倍率) - 怪物def, 1)`（与普攻的 `damage()` 不同函数）。本卡只解冻授权项"伤害公式 `max(atk-def,1)`"（怪物→玩家 / 玩家普攻），**没有顺路改技能路径**：

- 病根只在"怪物 atk 打高 def 玩家"这一侧；怪物 def 最高 12（僵尸王），玩家技能不存在免疫段。
- 改技能路径会同时改动三技能的全部验证页与 MP/冷却平衡，超出本卡授权。
- 已知不一致：同一场战斗里，玩家普攻按比例减伤、技能按减法减伤。**这是已知取舍，不是遗漏**；若要统一，应另开卡并重算三技能验证页。

## 6 缺口问答（数据版）

1. **新公式让游戏变简单还是变难？** 变难。50 局同种子：死亡回合中位数 10→7，F1 结束平均 HP 68.7→52.0，到 F3 的局数 14→9，死 F2 的局数 36→41。通关率仍 0。
2. **"每场战斗最优解都是按 1"有没有改善？** 没有。bot 的策略仍是 `att<%45 用药，否则按 1`——因为怪物行为单一（只有普攻/吐息，没有需要防御或逃跑的威胁结构），不是公式造成的。公式只改变了"按 1 打多久会死"，没有改变"按 1 是最优"。
3. **只有第 5 层变了会不会让难度曲线表述失真？** 本次**五层期望强度都没变**（Boss 不进表）。真正变化的是"期望受击伤害曲线"：旧 `1.00/1.50/1.75/3.35/1.25`（F4>F5 倒挂）→ 新 `3.25/6.75/7.30/11.75/12.90`（严格递增）。对外表述必须区分两个指标：**期望强度**（怪自身 hp/atk 的静态强度，未变）与**期望受击伤害**（玩家实际挨打，全层上移、F5 变最难）。只报前者会掩盖本卡的影响，只报后者会让人误以为怪表被改了。
