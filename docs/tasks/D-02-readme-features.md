## 六、取舍与已知缺口

1. **演示页快照是单次采样，波动很大**：本卡复核期间同一协议（单图、实时顺序训练）观测到 28 轮 7%、30 轮 17%、32 轮 19%、87 轮 13%、88 轮 16%、88 轮 17%、91 轮 16%。文档只写截图那一次的 88 轮 / 17%，并保留"随地图与轮次波动"的限定，不把它当稳定值。
2. **为什么取 88 轮而不是 C-05 截图的 33 轮**：33 轮时样本只有约 30 个 episode，成功率在 7%~21% 之间大幅跳动，截图容易给出误导性极值；延长到约 4800 步（≈88 轮）后数值稳定在 13%~17%，更接近演示页持续运行一分钟时观众看到的状态。仍是同一条训练路径，无任何参数改动。
3. **旧口径数字不出现在 README / 讲稿**：为了满足 D2-5，旧口径只以"历史顺序训练采样（未固定种子、ε 跨图衰减）"描述，不写具体旧区间与旧中位数；这既保留了不可比声明，也避免读者把旧数字当现状。
4. **D2-4 的百分数白名单范围**：只覆盖 Q-learning 相关段落；README 其他条目里的 45%、8%、2.5 倍等属于 S-04/S-05 行为描述，由 D2-1 对照数据文件校验，不混进 D2-4。
5. **未改 `对标自检报告.md`**：按卡面要求保持历史正文不动；现状说明只写在本卡与 `规划-对标补齐.md` 的追加节。
