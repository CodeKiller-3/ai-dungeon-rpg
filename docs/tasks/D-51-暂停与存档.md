# D-51 暂停菜单与存档管理 —— 玩到一半总得能停下来

> 性质：**功能卡，不碰数值**。数值线已在 D-50 封口；本卡没有改任何战斗 / 怪物 / 掉落 / 价格 / 经验 / 救援量。
> 目标：补上"游戏进行中"这层界面，让人能正常停下来、退出去、清掉坏档。

## 一、做了什么

| 入口 | 行为 |
| --- | --- |
| 游戏内 Esc | 打开暂停面板：继续游戏 / 设置 / 返回主菜单 / 放弃本局 |
| 暂停 → 继续游戏 | 从原位置、原时间轴继续；不丢输入锁、不跳帧 |
| 暂停 → 设置 | 打击感 / 音效 / 画面缩放 / 自适应难度 + **清除存档** |
| 暂停 → 返回主菜单 | 先 `Save.save()` 落盘，再静默终止本场战斗、回到首屏；「继续游戏」回到该局面 |
| 暂停 → 放弃本局 | 二次确认；**不写档**，磁盘上仍是这局之前的存档 |
| 设置 → 清除存档 | 二次确认；删除 `ai_dungeon_rpg_save_v1`，删后无档、主菜单 «继续游戏» 置灰；损坏档同样可删 |

视觉沿用 D-48 主菜单的深色网格 + 金色高亮 + 等宽像素字体；暂停面板是 `Render.drawPause()`，
不新开任何循环。

## 二、暂停为什么是"真停"

`Main.loop()` 在任何 update/tick 之前先过一道暂停闸门：

```
_updatePauseInput(ts)
if (pause.active) { _drawPause(); return; }
_settlePauseClock(ts)
... Feedback/Fx/Notice/Motion/Particles/Battle.tick/场景更新 ...
```

暂停期间被跳过的具体对象：

| 对象 | 暂停时的行为 |
| --- | --- |
| 玩家移动 | `_updateExplore` 不调用，步数计数不增长 |
| 怪物 AI | `AI.tick` 不调用，AI tick 计数不增长 |
| 战斗时间轴 | `Battle.tick` 不调用，`Battle._now()` 冻结 |
| 粒子 / 移动插值 | `Particles.update` / `Motion.update` 不调用 |
| 打击感 / 提示条 | `Fx.update` / `Feedback.update` / `Notice.update` 不调用 |
| 回合倒计时 | 暂停累计时长在恢复时一次性补给时钟偏移，剩余量原样保留 |

验证页的四类计数器（`Main._counters()`）：`steps` / `aiTicks` / `battleTicks` / `turnClock`。
暂停 180 帧（≈3 秒）后四项逐一相等；负例"每帧照常 `loop()`、只额外画一层暂停遮罩"时四项全部增长，
同一判据判定 FAIL——证明这条断言抓的正是"遮罩但游戏还在跑"。

## 三、战斗中暂停怎么挂起时间轴

`battle.js` 增加一个累计偏移 `timeOffset`：

- `now()` 统一返回 `frameNow - timeOffset`（注入时钟同理）。
- 暂停时记录 `pause.stoppedAt`（最后一帧 rAF 时间戳），**不推进** `Battle.tick`。
- 恢复首帧调用 `Battle._shiftClock(当前 ts − stoppedAt)`，把暂停期间的真实时长一次性补进偏移。

效果：恢复后 `now()` 仍等于暂停前的时刻，`pending.due` / `lockUntil` / `turnRec.finalizeAt`
的剩余量分毫不动。因此——

- **不跳帧**：怪物段不会因为"暂停了 3 秒"而立即结算；
- **不重复结算**：怪物段仍只由一次 `runMonsterSegment` 消费，验证页实测 `monster-hit` 恰好 1 次；
- **不丢输入锁**：恢复首帧 `isInputLocked()` 与暂停前一致，倒计时按剩余毫秒继续。

## 四、语义选择：放弃本局 = 丢进度，返回主菜单 = 保进度

- **返回主菜单**：先写档再走。存档就是"当前局面"，继续游戏逐项一致（HP / 层 / 背包 / 金币 / 等级）。
- **放弃本局**：明确不写档。存档仍指向这局之前最近一次自动存档；二次确认文案直接写
  "放弃后本次进度不会写入存档。若已有存档，继续游戏将回到最近一次自动存档。"

这样两个选项才有区别：否则"放弃本局"与"返回主菜单"完全等价，玩家没有真正的退出手段。
若本局从未触发过自动存档，磁盘上无档，主菜单 «继续游戏» 自然置灰。

## 五、清档防误删

1. 设置页把「清除存档」做成**动作行**（不是开关），显示当前是否有档。
2. 第一次 Enter 只切到确认页，**不删任何东西**；Esc / «取消» 原样返回。
3. 确认页默认停在 «确认»，需要再按一次 Enter；两次都是独立的按键边沿。
4. 删除只针对 `ai_dungeon_rpg_save_v1`，不碰设置键 `aiDungeon_settings_v1`；损坏档按同一 key 删除。
5. 从暂停面板清档后直接回主菜单，避免下一帧自动存档又把档写回来。

## 七、验收（`verify_d51` A–G 全绿）

- A：暂停 3 秒后步数 / AI tick / 战斗 tick / 回合计时不变；恢复后输入继续生效；"只盖遮罩"负例必须 FAIL。
- B：战斗内暂停 3 秒，怪物血量 / 玩家血量 / 回合号 / 时间轴起点 / 输入锁全不变；恢复不跳帧，怪物段只结算一次。
- C：暂停 → 返回主菜单 → 继续游戏，HP / 层 / 背包 / 金币 / 等级逐项一致。
- D：菜单 ↔ 场景往返 4 次后 `_rafChains=1`、待执行回调 1，再次 `start()` 返回 false。
- E：清档第一次只提示、Esc 取消不删、第二次才删；删后无档且 «继续游戏» 置灰；损坏档可清。
- F：四策略同种子复跑与 D-50 逐局一致，B1 14/50。
- G：旧档可读；存档键 `ai_dungeon_rpg_save_v1` 与设置键 `aiDungeon_settings_v1` 未变，无第二份存档键。
