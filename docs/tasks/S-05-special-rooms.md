# S-05 特殊房间（密室）

- 卡片编号：S-05
- 依据：`规划-对标补齐.md` §S-05
- 目标：给每层加一间"绕路才拿得到"的密室——单门封闭小房 + 厚赏大宝箱，把「风险回报」从"怪更多"扩到"值不值得绕"。这是 v2 六张卡的最后一张。
- 状态：已实现，`verify_s05.html` 9 组断言全 PASS，静态自检 32 PASS / 1 WARN / 0 FAIL，全量回归 39/39 PASS。

## 一、玩家可见行为

1. 第 2 层起，每层最多 1 间密室；第 1 层没有（新手层不塞诱惑）。
2. 密室是一块**四面封墙、只有一扇门**的小房（内部 4~6 × 3~4 格），房间中心有一个**发金光的大宝箱**，上方两角各一支火把；**房内没有陷阱**。
3. 密室中心离出生点至少 7 格（曼哈顿距离），不会一落地就白拿。
4. 从门口走进密室、踩到宝箱即自动开启：**厚金币（8~27 × 层数 × 2.5）+ 保底 1 件道具**（小药水 / 骨剑 / 皮甲 / 强化卷轴四选一）。
5. 开箱后宝箱消失（不可重复拾取），房间本身仍然存在，可以再进去。
6. 楼梯永远不会生成在密室内或门口，上下楼不受影响。

## 三、不许动

- 不改迷宫 DFS 与 `openRooms()` 的开洞概率（密室是在既有迷宫上"圈"出来的，不重写生成器）。
- 不改楼梯/出生点规则，只让楼梯避开密室与门口。
- 不改普通宝箱 `chest` 的掉落口径（50% 金币 / 50% 三件低阶物品），密室宝箱是独立分支。
- 不改怪物数值与 Boss 配置；不新增按键、不新增面板。
- 不把密室写进任务系统（不做"找到密室"类任务）。

## 六、取舍与已知缺口

1. **密室是"圈"出来的，不是"挖"出来的**。DFS 迷宫几乎不存在 4×3 的整片实心墙，原计划"在墙里挖房"实测 8 次重生成 0 成功；改为在既有迷宫里选一块矩形、把内部铺平、把四周封墙、只留一扇门，再跑"中心可达 + 堵门不可达 + 全图仍连通"三重校验。代价是房间外墙最多会切断原有走廊（已由全图连通校验兜住，切断就整体还原重试）。
2. **每层最多 1 间，允许 0 间**。40 次尝试全失败时该层就没有密室；实测 F2~F5 均 1 次即成，但没有硬保证。
3. **宝箱是"踩上去自动开"**，没有开箱动画、没有确认对话、没有"上锁/需要钥匙"的变体。
4. **密室只有一种模板**（金币+道具的厚赏房），没有规划里提到的"密室"变体（纯金币房 / 装备房 / 卷轴房按层权重分配）——当前统一走 `rich` 掉落，权重由四件道具池平摊。
5. **房内光照未特殊处理**；火把只是装饰贴图，不参与 M9-2 的动态光影。
6. **地图视觉没标出"这是密室"**：房间靠"四面墙 + 一扇门 + 中心发光宝箱"自解释，没有特殊地板材质或门框高亮。
7. **`room_chest` 贴图是自绘 16×16**（203 B），与既有 0x72 素材风格不完全同源，只做到"比普通宝箱更亮更大"的可辨识度。
