# D-115 可交互物统一标识（重点是楼梯）

日期：2026-11-18　范围：静态层（楼梯/陷阱/宝箱）+ NPC 脚下格　性质：纯表现层，`TOTAL_DIFF=0`

## 1 问题与裁定

D-113 把墙内缘压到 `#1a1024@0.90` 后，楼梯贴图（`floor_stairs` 深坑 / `floor_ladder`）与相邻墙内缘
同属近黑块，玩家走到楼梯旁看到"两团黑"。本卡不改 D-113 的墙体参数，只给可交互格加**类别标识**。

## 2 统一语法（四类）

语法 = **类别色 + 格内类别内框**；只画在已探明格，不铺满整格，不遮挡物件本体。

| 类别 | 类别色（84 色板） | 格内标记 | 依据 |
|---|---|---|---|
| 楼梯 | `#cae6f5` 青白 | 2px 内框（inset 2.5）+ 方向三角 10×8 | 新增；同色同类，方向靠三角朝向区分 |
| 宝箱 | `#ffcf6e` 金 | 沿用既有金色边框 | 卡片明确"金边与金币色已够，不要动" |
| 已发现陷阱 | `#d44e52` 红 | 1px 内框（inset 2），压在尖刺/气泡符号下 | 新增；只在 `tr.seen` 时出现 |
| NPC | `#79b85a` 绿 | 脚下格 1px 内框（inset 1），画在人形之前 | 新增；人形覆盖内框，不抢人 |

- 所有内框先 1px 深墨 `#16222e` 外描边，再压类别色：亮地板/暗墙上都有确定边界。
- **层级**：静态层（高于墙内缘暗边）→ 实体层（玩家/NPC 精灵覆盖它）。楼梯标识在
  `_drawSceneStatic` 的 t=2/3 分支内绘制；实体在 `drawMap` 后段与 `drawPlayer` 绘制。
- **FOV**：t=2/3 分支只在已探明时到达；未探明格仍整格 `#07070f`+tint，标识不泄露布局。
- 方向依据：下行 `▼`（宽边在上、尖端向下），上行 `▲`（宽边在下、尖端向上）；两像素带计数
  分别为 上/下 = **22/2**（下行）与 **4/16**（上行），符号在 24px 格内稳定可辨。

## 3 逐层 × 四档区分度量表

度量（均为真实地图、真实绘制、玩家站在楼梯邻格）：

- `p` = 楼梯格内 p95 线性亮度 / 四邻墙朝向楼梯的 3px 带均值；
- `m` = 楼梯格内均值 / 同上墙带均值；
- `b` = 亮像素占比（sRGB > 墙带均值 + 0.20）；
- `e` = 每条共享边的"楼梯侧 3px 带 − 墙侧 3px 带"最小值（sRGB）。

门槛（定为"一眼能认"而非贴线）：`p ≥ 5`、`m ≥ 3`、`b ≥ 0.15`、`e ≥ 0.10`，方向计数差 ≥4。

## 4 负例（真实可失败）

`R._interactMarks(false)` 回放 D-113 的纯贴图楼梯（F1 下行，320）：

`p=2.42`、`m=1.49`、`b=0.000`、`e=−0.035`（交界差为负）→ 四项全部达不到正例门槛，断言判红。

`verify_p2_3` 的 `d115.neg.legacyStair` 就是这条负例；打开标识后同一条断言转绿。

## 5 其他断言

- `d115.fovBlack`：未探明楼梯整格与格内左上角同色，亮度 0.058（<0.10）→ 标识不泄露。
- `d115.priority`：玩家站上楼梯后，格内上边框像素 `[197,224,239] → [182,203,207]`，
  且不再是类别色 → 精灵盖住标识（标识不能高于玩家/NPC）。
- D-113 四项（地板-墙比 / 交界差 / 地板不抬亮 / 五层色相）全部保持通过；未改任何墙体参数。
  唯一口径修正：D-113 的"地板均值/色相"样本改为只取 `t=1`（楼梯不是地板），阈值未动。
