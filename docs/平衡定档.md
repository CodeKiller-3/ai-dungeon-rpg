## 一、定档结论

**当前难度对真人是"能通、但要按规矩玩"：B1 机器人（不打怪、直奔 Boss 的打法）28%（14/50），
比 D-49 的 20% 高，比 D-48 的 14% 高；F5 的缺口不在药量，在回合数——平均还差 15.5 回合、
142.6 点 Boss 血量，折算 338 点有效治疗（4.2 瓶大血瓶 ≈ 169 金币），而规则只允许 150 金币。
所以 F5 依旧是一道硬门槛，救援只是把"差一口气"的局捞回来（本轮捞回 4 局），不是通行证。**

## 四、伤害公式与成长

**伤害（双方同一公式，`js/systems/battle.js#damage`）**

```
dmg = max(1, round(atk² / (atk + def)))
```

即减伤率 = def / (atk + def)。几个定档实例（可用公式复算）：

| 场景 | atk | def | 伤害 |
| --- | --- | --- | --- |
| 史莱姆打 L1 玩家 | 6 | 5 | 3 |
| 大僵尸打 def 15 的 F5 玩家 | 26 | 15 | 16 |
| 巨龙打 def 15 的 F5 玩家 | 32 | 15 | 22 |
| 狂暴巨龙打 def 15 的 F5 玩家 | 48 | 15 | 37 |
| 烈焰吐息打 def 15 的 F5 玩家 | 67 | 15 | 48 |

（def 15 是实测中 F5 玩家的常见防御值：本轮 16 局 F5 阵亡的最后一场，每回合承伤 22，
反解 `32²/(32+d)=22` 得 d≈15；狂暴后同一批局每回合 37，与 `48²/(48+15)=36.6` 吻合。）

**升级曲线（`js/systems/battle.js#expToNext`）**

```
expToNext(level) = base × level,  base = 15 (L1–L4) / 60 (L5+)
```

| 升级 | 所需经验 |
| --- | --- |
| L1→L2 | 15 |
| L2→L3 | 30 |
| L3→L4 | 45 |
| L4→L5 | 60 |
| L5→L6 | 300 |
| L6→L7 | 360 |
| L7→L8 | 420 |
| L8→L9 | 480 |
| L9→L10 | 540 |
| L10→L11 | 600 |

升级成长（`checkLevelUp` 兜底口径）：atk = 10 + (level−1)、def = 5 + (level−1)、
maxHp = 100 + (level−1)×10，升级即回满 HP/MP。

## 十、F5 那 38 次触发：差的到底是回合、药还是输出

D-49 口径下，B1 的 50 局里有 20 局死在第 5 层，共触发 38 次（F5 一级 18 次 + 三级 20 次）。
逐局取"最后一战"的实测回合日志（`d44` 逐回合记录的 dealt / taken / mhp / 用药），
用同一条恒等式拆解（数据源：`preflight/selfcheck/d50-legacy.json`，即 `form=d49` 的复现局）：

```
bossMax = dealt + bossLeft                    （输出账，逐局可复算）
hpPool  = 起始HP + Σ 药水回血                  （生存账）
死亡 ⟺ taken ≥ hpPool                          （实测成立）
T_need  = ceil(bossLeft / avgDealt)            （还差几回合）
addTaken= T_need × avgTaken                    （这几回合还要挨多少）
药缺口  = addTaken / 80（大血瓶）
```

折算治疗合计 6768（均值 338，≈4.2 瓶大血瓶 ≈ 169 金币）。

**占比口径**：

- **回合：100%（20/20）**——没有一局是"药够但打不动"，也没有一局是"再挨一下就能赢"；
  每一局都还需要额外的存活回合数才能把 Boss 打死。
- **药：只是买回合的价钱**。按 169 金币/局的均值算，已经超出 150 的上限 13%；
  20 局里有 17 局（85%）单局所需药量 ≥ 160 金币，3 局 ≥ 320 金币。
- **输出：是缺口的来源**。玩家在 F5 平均每回合打掉 10.3 点（20 局均值，2018 / 196 回合），
  同期每回合挨 20.7 点（4062 / 196），即"每 1 点输出要换 2.0 点治疗"；
  而巨龙 260 血 + 狂暴后 37/回合的承伤，把这条比值推到 1.6 以上时就没有解。

结论：**F5 不是药不够，是回合不够；回合不够的原因不是防御太低，是输出太低。**
这正是 D-45 的"白送最强武器仍差 30 血"与本节"给满 150 金币的药仍差 338 血"互相印证的同一件事。

## 十三、真人通关率估计

依据（不拍脑袋）：

1. B1 机器人是"不打怪、直奔 Boss"的极端打法，50 局只打了 198 只怪、平均 262 步；
   它在 F5 内的平均 HP 只有 55（满血均值 134，范围 110–160），到手的大血瓶平均 4 瓶。
2. 同一套数值下，真人会先清怪升级（升级回满 HP/MP）再进 Boss，且会把 F1–F4 奖励点给的
   470 金币里至少 280 换成 7 瓶大血瓶，而不是像机器人那样只带 4 瓶进 F5。
3. 按第十节的恒等式，F5 平均缺口 338 点治疗 = 4.2 瓶大血瓶；真人能多带 3 瓶以上，
   缺口补掉大半；再加上 F5 落点的 2 瓶特大血瓶（300 点治疗），单场有效血量可从
   机器人的 200–224 提到 550 以上。

据此估计：**没看过代码的真人首次通关率约 40%–55%**；熟悉路线、会留药、会先升级的玩家
可达 70% 以上。难度定位："需要规划，但不惩罚"。
