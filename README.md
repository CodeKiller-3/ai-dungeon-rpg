## 项目简介

一款可离线运行的像素风冒险 RPG 小游戏：随机迷宫探索、回合制战斗、背包装备、商店交易、任务系统、本地存档、**强化学习演示**一应俱全，并集成四层 AI 能力——**A\* 寻路、AI 行为状态机、大模型 NPC 对话、Q-learning 强化学习**。项目采用组件化拼装思路构建：站在开源巨人肩膀上，引入 GitHub 现成模块（javascript-astar、howler.js）与 freeCodeCamp 经典教程结构，全程零构建、零依赖，浏览器双击即玩。

## 功能列表

- 🗺️ 随机迷宫地图（DFS 回溯生成）· 5 层地牢 · 楼梯换层
- 🌿 **地图细节与装饰物**：tile 细节层（草丛/水洼/碎骨/苔藓，按权重随层生成）+ 装饰层（宝箱可拾取金币或道具、木桶、火把、藤蔓），纯视觉不影响通行/碰撞/寻路/FOV；迷雾外不绘制，素材就绪自动替换程序化绘制
- 🪤 **陷阱与状态**：每层随机布置 3~6 个陷阱（出生点 3 格内不放）· 第 1 层只出地刺，第 2 层起每个陷阱按 45% 概率为毒气 · 踩中结算一次后该格永久显现、不再伤人 · 地刺按当前 HP 8% 扣血（第 1 层单次 ≤15、其余层 ≤30）并附带流血（2 回合，每回合 −3 HP）· 毒气不直接扣血、改为中毒（3 回合，每回合 −2 HP）· 状态只作用于玩家，每「回合」（探索走一步 / 战斗行动一次）结算一次，同类状态取较大剩余回合、不叠层 · HUD 显示状态标记
- 🔐 **特殊房间（密室）**：第 2 层起每层最多 1 间封闭密室（内部 4~6 × 3~4 格，单扇门连通主迷宫，生成后校验可达性与全图连通性）· 房间中心固定 1 个密室宝箱（金币 2.5 倍 + 保底 1 件道具，可出强化卷轴），两侧火把 · 房内不放陷阱、不参与普通装饰抽位 · 楼梯不会生成在密室内部或门口
- 🌫️ **视野迷雾（FOV）**：玩家周围可见、墙后与远处变暗、走过的格子永久点亮
- 🔥 **光影与视野氛围**：火把格径向暖橙光晕（同屏上限 12，迷雾外不发光）· FOV 视野边缘 1-2 格软边 alpha 渐降（不改可见性语义）· 四角暗角 vignette 压暗（纯视觉层，渐变对象预建复用，60fps 友好）
- ✨ **动画与手感**：玩家/巡逻怪格子间移动平滑插值（easeOutQuad 缓出，逻辑坐标不变）· 怪物死亡消散（渐隐+上浮+缩小 700ms 后离场）· 攻击前摇帧（蓄力后拉→出手前冲→恢复，纯视觉不阻塞结算）· 四类粒子特效（spark 命中火花/puff 烟雾/shard 死亡碎片/soul 灵魂上浮，上限 60 粒/屏，enabled 低端开关）
- 📊 **顶部常驻 HUD**：HP/MP 短血条 · 金币 · 当前楼层 · 本层击杀进度（参考 Shattered Pixel Dungeon 信息栏）
- 🪟 **游戏内弹窗（背包/商店/任务）**：半透明遮罩 + 居中面板，Esc 或点遮罩关闭，键盘↑↓选择 + Enter 确认（使用/装备/购买/出售），鼠标点击条目直接操作
- 💥 **战斗视觉反馈**：命中伤害数字飘字（上飘渐隐 500-700ms，白/红区分敌我）· 怪物受击闪白+水平抖动 · 玩家受击红闪+屏幕边缘红晕（参考 Shattered Pixel Dungeon，纯新增展示层，不改任何战斗数值）
- ⚔️ 回合制战斗（攻击/防御/逃跑）· 经验金币掉落 · 死亡结算弹窗（楼层/击杀/金币/用时战绩 + 重新开始）
- 🔮 **技能系统**：火球 / 冲刺 / 护盾三技能（MP 50，消耗 12/8/10，冷却 3/2/4 回合）· 战斗中数字键 4/5/6 释放 · 护盾抵消 25% 最大生命伤害 · HUD 显示真实 MP
- 🐉 **Boss 二阶段**：地牢巨龙（第 5 层保底 Boss）血量 ≤50% 进入狂暴（攻击 ×1.5、防御 ×1.3）· 狂暴后每回合 30% 概率释放「烈焰吐息」（×1.4 伤害，可被防御减伤 50%）· 数值全部公式化、只触发一次、不写回原始数据（第 2 层独眼酋长、第 4 层僵尸王同为二阶段 Boss）
- 🎒 背包管理 · 血瓶使用 · 武器/防具装备加成 · 空状态提示（背包空/暂无任务居中灰字）· **行首 16×16 图标（48/48 物品显式映射，护甲与强化卷轴 4 档已补齐；逻辑宽 <420 时自动不画图标以保正文）**

- 🤖 **AI 亮点**：怪物 A\* 寻路追击 · 按种类分守卫 / 巡逻 / 追击三档习性与 3–8 格视距（隔墙看不见，守卫不追；巡逻怪与静态怪共用同一套感知，静态怪丢失目标会走回原位）· 贴脸触发战斗的行为状态机 · 大模型 NPC 自由对话（含离线兜底）· Q-learning 在线学习

- 🗡️ **精英专属武器（D-71/D-72）**：五层五把（断牙 / 裂颅 / 霜噬 / 守夜 / 烬牙），攻击 8 / 12 / 16 / 16 / 22，F4/F5 额外 +10 生命上限；打赢必掉、比当前武器强则自动装备、`price=sell=0` 且不可出售，商店核心货架与轮换池都买不到
- 💢 **伤害三档与碾压（D-70）**：单次伤害按目标生命上限分 normal / heavy / crush 三档，单次 ≥ 半血为 crush（橙红大字 + 冲击环）；1–2 回合解决普通怪额外给「碾压击杀」卡片，Boss 与精英不走碾压判定
- 🎴 **爽感表现层四件套（D-70）**：精英之证卡片 / 升级卡片（列出攻击·防御·生命上限前后值）/ 伤害分级 / 碾压击杀；只画不算——零 `Math.random`、不改任何数值与结算顺序，F 键切换关 / 低 / 高，off 档一个像素都不画

## 操作说明

| 按键 | 功能 |
|---|---|
| 方向键 / WASD | 移动（红点=埋伏怪，灰块=巡逻怪，紫梯=下，绿梯=上） |
| 1 / 2 / 3 | 战斗中：攻击 / 防御 / 逃跑 |
| 4 / 5 / 6 | 战斗中：火球 / 冲刺 / 护盾（消耗 MP，按回合冷却） |
| **7** | **战斗中：用药**（喝血瓶/魔法药，占一回合，怪物照常反击） |
| F | 战斗中：切换战斗特效（关 / 低 / 高） |
| B / E / M / T | 背包 / 商店 / 任务·图鉴（Tab 或 ←→ 切页）/ NPC 对话 |
| **L** | **Q-learning 寻宝鼠演示**（AI 学习，Esc 返回） |
| **K** | **一键静音**（音效+BGM 全部静音，再按恢复） |
| **Q** | **设置面板**（音量滑块拖拽/←→调节 · 静音开关 · 操作说明） |
| **H** | **重看引导**（目标 / 去向 / 完整按键表 / 机制须知） |
| ↑↓ + Enter | 列表中移动与确认 |
| **Esc** | **游戏内：暂停**（继续 / 设置 / 返回主菜单 / 放弃本局）；面板内：返回 / 关闭 |
| R | 通关画面 / 死亡结算：重新开始 |

- 面板布局边界：左列表单列、最大宽 520 逻辑像素；逻辑宽 < 700 时面板按单列绘制（88% 视口、上限 520，1366×768 下左右余量 195px）。逻辑宽 ≥ 700 时背包面板右侧展开 200 逻辑像素的只读装备栏，面板总宽上限 520 + 12 + 200 = 732，左右余量随视口收缩但不小于 16px（960×540 实测 114px、1024 逻辑宽实测 146px）。面板正文字号不低于 11px。

## 数值口径

- **地牢层数固定 5 层**。唯一权威来源是 `js/data/maps.js` 中 `MAPS.floors` 的数值；任何文档、任务卡、文案提到层数都以此为准（早期外部任务书里的旧层数口径已作废）。
- 物品 48 件、素材 207 张、验证页 109 个，分别以 `js/data/items.js` 的 `ITEMS` 条目数、`assets/sprites/*.png` 实际数量、`preflight/selfcheck/page-baseline.json` 的 `count` 为准。

## AI 亮点说明

| 模块 | 实现 |
|---|---|
| A\* 寻路 | 引入 GitHub 开源库 `javascript-astar`（MIT），怪物感知玩家后用 A\* 计算最短路径，每 4 帧重规划，沿路径逐格追击 |
| AI 行为状态机 | 巡逻怪与静态怪共用：IDLE（待机灰块）→ CHASE（各自 3–8 格视距内且视线不被墙挡住，变红块追击）→ ATTACK（贴脸触发战斗）；守卫型发现只警戒、原地不动。状态转移可视化（灰/红/! 标记） |
| NPC 对话 | 按 T 打开"地牢守门人"对话：配置 DeepSeek API Key 后为在线自由对话；无 Key/断网自动降级为离线规则问答 |
| Q-learning 寻宝鼠演示 | 按 L 打开演示：AI 寻宝鼠在真实迷宫网格上做标准 Q-learning 训练（ε-贪心策略 + 距离势引导），实时显示训练轮次与**最近 20 轮滚动成功率**走势（图上柱状与图例「近20轮」同口径，非累计）。**四组离线口径**（7 张固定种子地图 101/202/303/404/505/606/707、每图独立 learner 实例、60 步上限、每图训练 3000 步；成功率定义 = 60 步内从随机起点走到金币的轮次占比）：① **训练期（含探索）** 中位数 15%、区间 6%~26%；② **greedy 独立评估（训练后 ε=0、Q 冻结、独立随机起点）** 中位数 13%、区间 2%~25%；③ **R1 基线（4 动作均匀、撞墙算一步，对应玩家乱按方向键）** 中位数 5%、区间 2%~13%；④ **R2 基线（合法动作里均匀，标准 random policy）** 中位数 7%、区间 2%~13%。演示页（游戏内 L）为单张地图实时顺序训练，固定种子单图（909）训练到第 88 轮的读数为成功率 3%（训练期含探索，单次采样，随地图与轮次波动）。全部数字落盘 `preflight/selfcheck/d13-evidence.json`。**长训指标另走离线路径**（每图训满 3000 episode 的 greedy 评估），落盘 `preflight/selfcheck/d36-metrics.json`，与演示路径分开计量、互不冒充。**口径不可混**：训练期含探索与 greedy 独立评估不是同一协议、不可比，不得表述为「提升」；实时训练随地图波动，不宣称稳定收敛。 |

## 运行方式

**方式一（推荐）**：双击 `index.html` 直接在浏览器运行（已适配 file:// 协议，无需服务器）。

**方式二**：GitHub Pages 在线试玩（上方链接）。

**开启在线 AI 对话（可选）**：编辑 `js/data/config.js` 填入 `deepseekKey`（仅本地使用，不会上传代码仓库）。获取 Key 见 <https://platform.deepseek.com>。
